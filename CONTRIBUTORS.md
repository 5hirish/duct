# Contributors

Code, design, and content are all "contributions" in the same sense — work
that made the project better and wasn't the maintainer's alone. This file
credits the ones that don't show up as cleanly in `git log` as a commit does:
a landing page draft, a contrast fix, a blog post idea that became a post.

**Add yourself here in the same PR that lands your contribution**, under
whichever section fits, newest at the top. No contribution is too small to be
listed for. (The maintainer isn't listed here — that's already in
[`CODEOWNERS`](.github/CODEOWNERS) and the git history.)
