Five commands from an empty folder to Duct on your machine. The README covers the rest.

terminal
$ git clone https://github.com/5hirish/duct.git && cd duct
$ make setup
$ cp backend/.env.example backend/.env.local   # add one model provider key
$ make serve-backend                            # then, in a second terminal:
$ make serve-app

Questions people ask

Is Duct really free?

Yes. Duct is MIT licensed and free with your own model keys. You pay your model provider directly, or sign in with the ChatGPT plan you already have.

Can I run Duct without an account?

Yes. Clone the repository, run make setup, add one model key and start the backend and the app. No account with Duct is involved.

What do I give up by self-hosting?

Google Ads, GA4 and Search Console need your own Google OAuth client before they connect, and the database, backups and upgrades are yours to run.

Can I use Duct commercially or fork it?

Yes. The MIT license allows commercial use, changes and redistribution. The exceptions are third-party documentation under docs/guides and the Duct name and mark.

How do I contribute?

Start with CONTRIBUTING.md. The roadmap is a public board, and a pull request written with an agent is welcome if it says where the agent helped.
