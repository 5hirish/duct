DuctのMCPサーバー · ブラウザサインイン

エージェントからDuctを使用します。
コピーするトークンはありません。

このアドレスをClaude Code、Codex、Cursor、VS Code、OpenCode、Claude、またはChatGPTに追加します。Ductでブラウザが開き、「許可」をクリックすると、エージェントがプロジェクトを読み取り、その詳細を下書きできるようになります。

サーバーアドレス 
https://api.getduct.ai/mcp

Duct自身のエージェントにMCPサーバーを呼び出させたいですか？それは逆方向です：Duct内のMCPサーバー →

エージェントの接続方法

追加し、許可し、質問します。

01

エージェントにDuctを追加

上記のアドレスを、1つのコマンドまたは1行の設定でエージェントに与えてください。各エージェントの正確な手順は以下にあります。

$ claude mcp add \
    --transport http \
    --scope user duct \
    https://api.getduct.ai/mcp
02

サインインして「許可」をクリック

ブラウザでDuctが開かれ、あなたのアカウントをエージェントが使用することを許可するか尋ねられます。「許可」をクリックしてください。コピーするトークンはありません。

Duct

Claude CodeがあなたのDuctアカウントの使用を希望しています

キャンセル許可する
03

何か質問します

「Ductでこの製品を設定」を試してください。エージェントがリポジトリを読み取り、プロジェクトの説明、ターゲット層、競合他社を下書きします。

Ductでこの製品を設定します。

リポジトリから説明、オーディエンス、競合を下書きしました。それらはDuctのプロジェクトにあります。

エージェントによる設定

7つのエージェント。1つのアドレス。

すべてのエージェントは同じサーバーに接続します。正確な手順については、お使いのエージェントを選択してください。

Claude Code

  1. ターミナルで実行： 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. Claude Codeで/mcpを実行し、ductを選択してAuthenticateを選びます。
  3. ブラウザでDuctが開きます。「許可」をクリックしてください。

Codex

  1. ターミナルで実行： 
    codex mcp add duct --url https://api.getduct.ai/mcp
  2. 次にサインイン： 
    codex mcp login duct
  3. ブラウザでDuctが開きます。「許可」をクリックしてください。

Cursor

  1. ~/.cursor/mcp.jsonにDuctを追加します: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. CursorのMCP設定で、ductサーバーのログインプロンプトを押します。
  3. ブラウザでDuctが開きます。「許可」をクリックしてください。

VS Code

  1. コマンドパレットを開き、MCP: Add Serverを実行します。
  2. HTTPを選択し、アドレスを貼り付け、ductと名付けます: 
    https://api.getduct.ai/mcp
  3. VS Codeは、Ductを初めて使用する際にサインインを求めます。ブラウザでDuctが開き、「許可」をクリックします。

OpenCode

  1. opencode.jsonにDuctを追加します: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. 次にサインイン： 
    opencode mcp auth duct
  3. ブラウザでDuctが開きます。「許可」をクリックしてください。

Claude (claude.aiまたはClaude Desktop)

  1. claude.aiまたはClaude Desktopで、「設定」→「コネクタ」を開き、「カスタムコネクタを追加」を選択します。
  2. Ductと名付けてアドレスを貼り付けます： 
    https://api.getduct.ai/mcp
  3. 「接続」を押します。Ductがブラウザで開きます。「許可」をクリックします。

ChatGPT

  1. ChatGPTの設定で、開発者モードをオンにします。
  2. このアドレスでコネクタを追加し、認証にはOAuthを選択します: 
    https://api.getduct.ai/mcp
  3. Ductがブラウザで開きます。「許可」をクリックしてください。

他のエージェントですか？アドレスでリモートMCPサーバーを追加できる場合は、同じアドレスを与えてください。サインインできない場合は、トークンを使用してください。

エージェントができること

読み取りと下書きを行います。決定するのはあなたです。

Ductは現在、エージェントに3つのツールを提供しています。承認、適用、接続はDuctであなたが行います。

あなたのエージェントは
  • プロジェクトを一覧表示します。
  • 1つのプロジェクトを読み取ります。
  • リポジトリまたはファイルから、プロジェクトの説明、オーディエンス、競合を下書きします。
決してできません
  • 変更を承認または適用します。
  • ツールを接続します。
  • キーまたは認証情報を表示します。
  • Ductに入力した内容を上書きします。下書きは空白を埋めるか、以前の下書きを置き換えるだけです。

すべての変更はプロジェクトのアクティビティに表示されます。

アクセス

すべてのエージェントが一覧表示されています。いずれかを切断します。

接続されているすべてのエージェントが表示されます

Ductで「設定」→「AIエージェントを接続」を開きます。許可したすべてのエージェントがここに表示され、切断できます。切断されたエージェントは次回の呼び出しで停止します。

ブラウザがない場合：トークンを使用します。

CI、リモートマシン、またはサインインなしのエージェント向けです。同じ設定ページの「ブラウザなし？トークンを使用」の下で作成してください。エージェントはこれをヘッダーとして送信します。

Authorization: Bearer duct_mcp_…

Claude Codeで：

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

トラブルシューティング

行き詰まりましたか？ここから始めましょう。

ブラウザが開きませんでした

自分でサインインを開始します：Claude Codeで/mcp、Codexでcodex mcp login duct、またはOpenCodeでopencode mcp auth ductを実行します。

登録できなかった、または「動的クライアント登録をサポートしていません」と表示されます

エージェントを最新バージョンに更新して、もう一度お試しください。それでも失敗する場合は、代わりにトークンで接続してください。

動作しましたが、401エラーが発生します

Ductで接続を切断したか、90日間使用されなかったためサインインが失効しました。エージェントから再度サインインしてください。

プロジェクトの設定を依頼しましたが、何も変更されませんでした

下書きはDuctで入力した内容を上書きすることはありません。空白のフィールドを埋めるか、以前の下書きを置き換えるだけです。Ductのプロジェクトページをご確認ください。

自分でDuctをホストしています

https://api.getduct.ai/mcpの代わりに、ご自身のAPIアドレスに/mcpを続けて使用します。
