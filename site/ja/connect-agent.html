選択する

プロジェクトのセットアップ、またはあなたと一緒に作業します。

エージェントがサインインするとき、どのプロジェクトで何の操作ができるかを設定します。設定でいつでも変更できます。

  • プロジェクトのセットアップを支援。 リポジトリからプロジェクトの概要、ターゲット層、競合他社の下書きを作成します。
  • 共同作業を行う。 ツールを読み取り、重要な事項を記憶し、ブリーフを作成します。提案された変更、投稿の下書き、ご自身のキーを使用した画像生成は、有効にするまでオフのままです。
  • すべてのプロジェクト、または選択したプロジェクトのみ。

許可する操作の最終決定権は常にユーザーにあります: 変更の承認や適用、公開、ツールの接続、パスワードやキー。保存されたすべての操作はアクティビティにエージェント名で表示され、編集はワンクリックで元に戻せます。

エージェントによるセットアップ

8つのエージェント。1つのアドレス。

すべてのエージェントが同じアドレスに接続します。お使いのエージェントを選択してください。

Claude Code

  1. ターミナルで以下を実行します: 
    claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp
  2. Claude Codeで/mcpを実行し、ductを選択してAuthenticateを選びます。
  3. ブラウザで実行可能な操作を選択し、Allowをクリックします。
  4. Ductのブリーフプレイブックを使用するには/mcp__duct__insights_briefを実行するか、質問してください。

Codex

  1. ターミナルで以下を実行します: 
    codex mcp add duct --url https://mcp.getduct.ai/mcp
  2. 次にサインイン: 
    codex mcp login duct
  3. ブラウザで実行可能な操作を選択し、Allowをクリックします。

Cursor

  1. ~/.cursor/mcp.jsonにDuctを追加: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. CursorのMCP設定で、ductのLoginを押します。
  3. ブラウザで実行可能な操作を選択し、Allowをクリックします。

Gemini CLI

  1. ~/.gemini/settings.jsonにDuctを追加: 
    {
  "mcpServers": {
    "duct": {
      "httpUrl": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Gemini CLIを起動してサインイン: 
    /mcp auth duct
  3. ブラウザで実行可能な操作を選択し、Allowをクリックします。
  4. Ductのブリーフプレイブックを使用するには/insights_briefを実行するか、質問してください。

VS Code

  1. コマンドパレットを開き、MCP: Add Serverを実行します。
  2. HTTPを選択し、アドレスを貼り付けて名前をductにします: 
    https://mcp.getduct.ai/mcp
  3. 初回起動時、VS Codeからサインインを求められます。ブラウザで実行できる操作を選択し、「許可」をクリックします。

OpenCode

  1. opencode.jsonにDuctを追加: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. 次にサインイン: 
    opencode mcp auth duct
  3. ブラウザで実行可能な操作を選択し、Allowをクリックします。

Claude (claude.aiまたはClaude Desktop)

  1. 設定 → コネクタを開き、カスタムコネクタを追加を選択します。
  2. 名前をDuctにして、アドレスを貼り付けます: 
    https://mcp.getduct.ai/mcp
  3. Connectを押します。ブラウザで実行可能な操作を選択し、Allowをクリックします。

ChatGPT

  1. ChatGPTの設定で、開発者モードをオンにします。
  2. このアドレスとOAuthサインインでコネクタを追加: 
    https://mcp.getduct.ai/mcp
  3. ブラウザで実行可能な操作を選択し、Allowをクリックします。

別のエージェントをお使いですか？同じアドレスを指定するか、サインインできない場合はトークンを使用してください。

ブラウザがない場合：トークンを使用します。

CIやリモートマシン用。設定 → AIエージェントを接続で同様の選択肢から作成します。そのページには許可したすべてのエージェントが一覧表示され、個別に切断も可能です。ヘッダーとして送信してください:

質問

よくある質問。そして解決策。

接続する前に

APIキーは必要ですか？

いいえ。すでにお支払い中のプランで動作します。保存されたキーは画像とスケジュールされたブリーフにのみ使用されます。

どのツールを読み取ることができますか？

Stripe、Meta Ads、Mixpanel、GitHub、RevenueCatなどはDuctで接続します。Google Analytics、Search Console、Google Ads、Tag Managerは、外部アシスタントに関するGoogleのポリシーが確認されるまで、当面はDuct自身のエージェントに残ります。

広告アカウントを変更することはできますか？

有効にした場合、提案としてのみ作成されます。承認するまでDuct内で待機します。エージェントが変更を適用することはありません。

Ductは会話内容を閲覧できますか？

いいえ。Ductはエージェントからの呼び出しのみを参照し、チャットの残りの内容は参照しません。

ノートPCを閉じている間もブリーフは実行されますか？

エージェントからは実行されません。午前3時に稼働するエージェントはないため、スケジュールされたブリーフは保存されたキーでDuct内で実行されます。

問題が発生した場合

ブラウザが開きませんでした

手動で開始: Claude Codeで /mcp、codex mcp login duct、Gemini CLIで /mcp auth duct、または opencode mcp auth duct。

登録できなかった、または「動的クライアント登録をサポートしていません」と表示されます

エージェントを更新して再試行してください。それでも失敗する場合はトークンを使用してください。

動作しましたが、401エラーが発生します

切断されたか、90日間使用されていません。エージェントから再度サインインしてください。

必要なツールが見つかりません

許可された情報のみを参照します。Ductで接続を解除し、再接続してWork alongside meを選択してください。

自分でDuctをホストしています

自身のAPIアドレスの末尾に /mcp を付けて使用します。
