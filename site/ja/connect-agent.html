コンテンツへスキップ

エージェントからDuctを使用できます。トークンのコピーは不要です。

アドレスを1つエージェントに貼り付け、一度「許可」をクリックすると、Ductプロジェクトの読み取りと下書き作成が可能になります。

https://api.getduct.ai/mcp

セットアップ：

  • Claude Code
  • Codex
  • Cursor
  • VS Code
  • OpenCode
  • Claude
  • ChatGPT

エージェントを選択します。1行貼り付けます。

Claude Code

  1. ターミナルで以下を実行します： 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. Claude Codeで/mcpを実行し、ductを選択、Authenticateを選んで許可をクリックします。

Codex

  1. ターミナルで以下を実行します： 
    codex mcp add duct --url https://api.getduct.ai/mcp
    codex mcp login duct
  2. ブラウザでDuctが開きます。「許可」をクリックしてください。

Cursor

  1. 以下を~/.cursor/mcp.jsonに追加します： 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. CursorのMCP設定でductにサインインし、許可をクリックします。

VS Code

  1. コマンドパレットからMCP: Add Serverを実行し、HTTPを選択して以下を貼り付けます： 
    https://api.getduct.ai/mcp
  2. 名前をductにします。初めてDuctを使用する際は、ブラウザで「許可」をクリックしてください。

OpenCode

  1. ターミナルで以下を実行します： 
    opencode mcp add duct --global --url https://api.getduct.ai/mcp
    opencode mcp auth duct
  2. ブラウザでDuctが開きます。「許可」をクリックしてください。

Claude (claude.aiまたはClaude Desktop)

  1. 設定 → コネクタで「カスタムコネクタを追加」を選択し、名前をDuctにして以下を貼り付けます： 
    https://api.getduct.ai/mcp
  2. 「接続」を押し、「許可」をクリックします。

ChatGPT

  1. ChatGPTの設定で、開発者モードをオンにします。
  2. OAuthと以下のアドレスを使用してコネクタを追加します： 
    https://api.getduct.ai/mcp
  3. ブラウザでDuctが開きます。「許可」をクリックしてください。

別のエージェントをお使いですか？アドレスでリモートMCPサーバーを追加できるエージェントであれば動作します。サインインできない場合は、トークンを使用してください。

あとは自然な言葉で質問するだけです。

リポジトリやファイルからプロジェクトの読み取りと下書き作成を行います。Ductでの編集はいつでも元に戻せます。

ツールへの変更を承認・適用したり、新しいツールを接続したり、キーを参照したりすることは決してありません。

  • Ductでこの製品を設定します。

    draft_projectピッチ、ターゲット層、競合他社を元に下書きを作成します。入力した内容は保持されます。

  • Ductは私たちのオーディエンスについて何を把握していますか？

    get_projectプロジェクトと、各回答の参照元を読み取ります。

  • 競合他社からAcmeを削除してください。

    update_project依頼された内容のみを変更します。アクティビティから元に戻すことができます。

すべてのエージェントを確認し、任意のエージェントを切断できます。

Ductの「設定」→「AIエージェントの接続」に許可した各エージェントが表示されます。接続を解除すると、次の呼び出し時に停止します。

ブラウザがない場合：トークンを使用します。

CIまたはリモートマシン用。同じ設定ページで作成してください。エージェントがヘッダーとして送信します。

Authorization: Bearer duct_mcp_…

Claude Codeで：

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

お困りですか？ここから始めましょう。

ブラウザが開きませんでした

自分でサインインを開始します：Claude Codeで/mcp、Codexでcodex mcp login duct、またはOpenCodeでopencode mcp auth ductを実行します。

登録できなかった、または「動的クライアント登録をサポートしていません」と表示されます

エージェントを最新バージョンに更新して、もう一度お試しください。それでも失敗する場合は、代わりにトークンで接続してください。

動作しましたが、401エラーが発生します

Ductで接続を切断したか、90日間使用されなかったためサインインが失効しました。エージェントから再度サインインしてください。

プロジェクトの設定を依頼しましたが、何も変更されませんでした

下書きがDuctに入力した内容を上書きすることはありません。空の項目を埋めるか、以前の下書きを置き換えるのみです。設定したフィールドを変更したい場合は、項目名を指定して修正を依頼してください。

自分でDuctをホストしています

https://api.getduct.ai/mcpの代わりに、ご自身のAPIアドレスに/mcpを続けて使用します。

エージェントに貼り付け、「許可」をクリックします。
