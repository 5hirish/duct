Ductという名前の由来

水道橋にちなんで名付けられました。

Ductはラテン語のductusに由来し、「導く」という意味です。aquaeductus（水を導くもの）という言葉の中にあります。ローマの水道橋は一滴の水も作りませんでした。水源にはすでに水があり、ローマは重力のみで水を人々の住む場所へ運ぶ水路を建設しました。

お客様のスタックは同じです。広告、アナリティクス、検索、収益：それぞれの源泉は問題ありません。欠けているのは、それらと意思決定をつなぐチャネルです。それがDuctの役割であり、名前の由来です。

だからこそ、アプリはロボットではなく、ローマの敷居のモザイクSALVEであなたを迎えます。そして、すべてが追いつくと水が満ち溢れるのです。全ストーリー →

macOS — ユニバーサルで、AppleシリコンとIntelの両方で動作します。macOS 12以降が必要です。Appleによって署名および公証されているため、警告なしで開きます。

Windows — Windows 10以降。インストーラーはまだコード署名されていないため、初回実行時にSmartScreenが「WindowsによってPCが保護されました」と表示します。詳細情報 → 実行をクリックしてください。現在修正中です。

Linux — AppImageはどこでも実行できます（最初にchmod +xしてください）。.debはDebianおよびUbuntu用です。プロバイダーキーには、GNOME Keyring、KWallet、KeePassXCなどのキーリングデーモンが必要です。

モデルキーはあなたのものです。 Ductはキー持ち込み型です。Anthropic、OpenAI、またはGeminiのキーを貼り付けると、デスクトップアプリはそれをブラウザタブではなくOSのキーチェーンに保存します。または、既存のChatGPTプランでサインインしてください。料金はプロバイダーから請求され、当社からは請求されません。
