ビジネス全体を読み取ります。だから、あなたもそれを理解できます。

Ductのすべてのパーツは、MITライセンスの1つの公開リポジトリに収められています。ダウンロードして弊社にサービスを実行させるか、クローンしてすべてをご自身で実行できます。

Ductをダウンロード ↓ ソースコードを読む

ご自身のモデルキーを使えば無料。

提案はエージェントが。適用できるのはあなただけ。

これらは、エージェントがアカウントを変更するために取得するすべてのツールです。変更を承認するツールはありません。単独で動作する唯一のツールはロールバックで、適用した変更のみを元に戻します。

backend/agents/tools/execution_tools.py
async def list_executable_ops(…)
async def propose_changes(…)
async def get_change_set_status(…)
async def rollback_change_set(…)

Doctrine は、このようなすべてのルールを、それを適用するファイルにリンクします。

同じコード。2つの実行方法。

アプリをダウンロードすれば、弊社がサービスを実行します。リポジトリをクローンすれば、すべてのパーツがあなたのものになります。

デスクトップアプリ多くの方がここから開始しますセルフホストデータの所在に関する規則向け
ご自身のモデルキーキーチェーン内お使いのマシン上
ツールのログイン情報、ブリーフ、メモリDuctのサービス上で暗号化お使いのマシンまたはサーバー上
チームメンバーやその他のコンピュータ1件の招待サーバーとしてホスト
データベースとアップグレード弊社が実行ご自身で実行
Duct アカウントはいなし

いずれの方法でも、お客様のAIキーを弊社が保持することはありません。詳細はプライバシーポリシーをご覧ください。

クローンして、キーを1つ追加し、起動します。

空のフォルダからお使いのマシンでDuctを動かすまで5つのコマンド。READMEに詳細が記載されています。

ターミナル
$ git clone https://github.com/5hirish/duct.git && cd duct
$ make setup
$ cp backend/.env.example backend/.env.local   # add one model provider key
$ make serve-backend                            # then, in a second terminal:
$ make serve-app

ご自身のキーを使えば無料。いつでも。

使用した分だけモデルプロバイダーに支払うか、すでにお持ちのChatGPTプランを使用します。Ductからの請求はありません。

よくある質問

Ductは本当に無料ですか？

はい。DuctはMITライセンスであり、ご自身のモデルキーを使えば無料です。モデルプロバイダーに直接支払うか、すでにお持ちのChatGPTプランでサインインします。

アカウントなしでDuctを実行できますか？

はい。リポジトリをクローンし、make setupを実行し、モデルキーを1つ追加して、バックエンドとアプリを起動します。Ductのアカウントは一切不要です。

セルフホストで失われるものは何ですか？

Google Ads、GA4、Search Consoleの接続には独自のGoogle OAuthクライアントが必要です。また、データベース、バックアップ、アップグレードの運用はご自身で行います。

Ductを商用利用したり、フォークしたりできますか？

はい。MITライセンスは商用利用、変更、再配布を許可しています。例外はdocs/guides以下のサードパーティドキュメント、およびDuctの名称とマークです。

貢献するにはどうすればよいですか？

CONTRIBUTING.mdから始めましょう。ロードマップは公開ボードであり、エージェントが支援した箇所が明記されていれば、エージェントを使って作成されたプルリクエストも歓迎します。
