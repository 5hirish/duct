ビジネス全体を読み取ります。
だから、あなたも読み取ることができます。

Ductはエージェント、コネクタ、プロンプト、承認ゲート、デスクトップシェルまで、エンドツーエンドでオープンソースです。ダウンロードすれば弊社がサービスを運用します。クローンすれば弊社は何も関与しません。

Ductをダウンロード ↓ ソースを読む

独自のキーで常に無料 · ご自身で実行するのにアカウントは不要です

01

すべてへの読み取りアクセスは、多くの要求です。

Ductは広告、アナリティクス、収益、セッションリプレイをまとめて読み取ります。この視点を持つツールはブラックボックスであるべきではありません。すべてのAPIコールとすべてのプロンプトはリポジトリにあり、接続する前に読み取ることができます。

02

承認ゲートはプロンプトではなく、コード内に存在します。

エージェントは変更を提案し、プレビューできます。承認または適用するツールはありません。それはあなたのボタンであり、モデルがそれを見ることはありません。ドクトリンは各ルールを、それを強制するファイルにリンクしています。

03

一人の人間は信頼を求めることはできません。コードを示すことはできます。

Ductはスペインの1人のメンテナーによって構築されており、エージェントがほとんどのタイピングを行っています。ロードマップは公開ボードであり、決定はイシューで議論され、お客様またはお客様のエージェントからのプルリクエストも同じレビューを受けます。

何がどこで実行されるか

同じコード。2つの実行方法。

アプリをダウンロードすると、弊社がその背後にあるサービスを運用します。サインインし、ツールを接続し、質問してください。コードをクローンすると、そのすべての部分をお客様が運用できます。どこに何があるかを分かりやすく説明します。

ご自身で実行する

クローンしてください。キーを1つ追加してください。両方の部分を開始してください。

バックエンドはFastAPI、アプリはNext.jsで、1つのMakefileが両方を駆動します。envファイルにモデルプロバイダーキーを追加すれば、数分で自分のマシンから自分のツールを読み取ることができます。

READMEはセットアップの信頼できる情報源であり、バックエンドがバンドルされたデスクトップビルドについても説明しています。ディスク上のSQLite、ループバックのみ、アカウント不要です。CONTRIBUTING.mdにはCIが実行するチェックが記載されています。

ターミナル 
$ git clone https://github.com/5hirish/duct.git && cd duct
$ make setup
$ cp backend/.env.example backend/.env.local   # add one model provider key
$ make serve-backend                            # then, in a second terminal:
$ make serve-app

費用がかかるもの

独自のキーで無料です。常に。

MITライセンスは試用版ではありません。 エージェント、コネクタ、承認ゲートが製品であり、リポジトリに含まれています。お客様ご自身のモデルキー、または既にお支払い済みのChatGPTプランで実行すれば、弊社に何も負うものはありません。

後日提供されるのは、モデルをバンドルした有料プランです。これにより、チームはAPIキーを持つことなくDuctを利用でき、デスクトップアプリが既に通信しているホスト型サービスの上に構築されます。現在オープンなものが、そのプランの背後に移動することはありません。もし変更がある場合は、コードが変更される前にこのページでお知らせします。

質問

人々が実際に尋ねるもの

Ductは本当に無料ですか？

はい。DuctはMITライセンスで、独自のモデルキーがあれば無料であり、それは変わりません。モデルプロバイダーに直接支払うか、既にお持ちのChatGPTプランでサインインしてください。後日、キーを保持したくないチーム向けにモデルアクセスをバンドルする有料プランが提供されるかもしれませんが、現在オープンなものがその背後に移動することはありません。

アカウントなしでDuctを実行できますか？

はい。リポジトリをクローンし、make setupを実行し、モデルプロバイダーキーを1つ追加して、バックエンドとアプリを起動します。すべてはあなたのマシンまたはサーバーに残り、Ductとのアカウントは一切関与しません。

Ductを商用利用したり、フォークしたりできますか？

はい。MITライセンスは商用利用、変更、再配布を許可しています。唯一の例外はdocs/guides以下のサードパーティドキュメントと、Ductの名称およびマークです。

貢献するにはどうすればよいですか？

CONTRIBUTING.mdから始めてください。課題と議論はGitHubにあり、ロードマップは公開プロジェクトボードです。エージェントが作成した貢献も歓迎しますが、プルリクエストにエージェントがどこで協力したかを明記してください。
