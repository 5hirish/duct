Escolha seu agente. Cole uma linha.

Claude Code

  1. Execute isto no seu terminal: 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. No Claude Code, execute /mcp, escolha duct, selecione Authenticate e clique em Permitir.

Codex

  1. Execute estes comandos no seu terminal: 
    codex mcp add duct --url https://api.getduct.ai/mcp
    codex mcp login duct
  2. Seu navegador abre no Duct. Clique em Permitir.

Cursor

  1. Adicione isto ao ~/.cursor/mcp.json: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Nas configurações de MCP do Cursor, entre no duct e clique em Permitir.

VS Code

  1. Na Paleta de comandos, execute MCP: Add Server, escolha HTTP e cole: 
    https://api.getduct.ai/mcp
  2. Nomeie como duct. Na primeira vez que ele usar o Duct, clique em Permitir no seu navegador.

OpenCode

  1. Execute estes comandos no seu terminal: 
    opencode mcp add duct --global --url https://api.getduct.ai/mcp
    opencode mcp auth duct
  2. Seu navegador abre no Duct. Clique em Permitir.

Claude, em claude.ai ou Claude Desktop

  1. Em Configurações → Conectores, escolha Adicionar conector personalizado, nomeie como Duct e cole: 
    https://api.getduct.ai/mcp
  2. Pressione Conectar e clique em Permitir.

ChatGPT

  1. Nas configurações do ChatGPT, ative o modo de desenvolvedor.
  2. Adicione um conector com OAuth e este endereço: 
    https://api.getduct.ai/mcp
  3. Seu navegador abre no Duct. Clique em Permitir.

Outro agente? Qualquer um que adicione um servidor MCP remoto por endereço funciona. Se ele não conseguir entrar, use um token.

Meu navegador nunca abriu

Inicie o login você mesmo: execute /mcp no Claude Code, codex mcp login duct no Codex, ou opencode mcp auth duct no OpenCode.

Ele diz que não conseguiu registrar, ou “não suporta registro dinâmico de cliente”

Atualize seu agente para a versão mais recente e tente novamente. Se ainda falhar, conecte-se com um token em vez disso.

Funcionou, e agora ele recebe um 401

Você o desconectou no Duct, ou seu acesso expirou após 90 dias sem uso. Entre novamente pelo seu agente.

Eu pedi para ele configurar o projeto e nada mudou

Um rascunho nunca sobrescreve o que você digitou no Duct. Ele só preenche campos em branco ou substitui um rascunho anterior. Para alterar um campo que você definiu, peça essa edição pelo nome.
