Como conectar seu agente

Adicione-o, permita-o, pergunte a ele.

01

Adicione o Duct ao seu agente

Dê ao seu agente o endereço acima, com um comando ou uma linha de configurações. Os passos exatos para cada agente estão abaixo.

$ claude mcp add \
    --transport http \
    --scope user duct \
    https://api.getduct.ai/mcp
02

Entrar e clique em Permitir

Seu navegador abre no Duct e pergunta se seu agente pode usar sua conta. Clique em Permitir. Não há token para copiar.

Configuração por agente

Sete agentes. Um endereço.

Todo agente se conecta ao mesmo servidor. Escolha o seu para os passos exatos.

Claude Code

  1. No seu terminal, execute: 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. No Claude Code, execute /mcp, selecione duct e escolha Autenticar.
  3. Seu navegador abre no Duct. Clique em Permitir.

Codex

  1. No seu terminal, execute: 
    codex mcp add duct --url https://api.getduct.ai/mcp
  2. Então entre: 
    codex mcp login duct
  3. Seu navegador abre no Duct. Clique em Permitir.

Cursor

  1. Adicione Duct a ~/.cursor/mcp.json: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Nas configurações de MCP do Cursor, pressione o prompt de login no servidor duct.
  3. Seu navegador abre no Duct. Clique em Permitir.

VS Code

  1. Abra a Paleta de Comandos e execute MCP: Adicionar Servidor.
  2. Escolha HTTP, cole o endereço e nomeie-o duct: 
    https://api.getduct.ai/mcp
  3. O VS Code pede para você entrar na primeira vez que usa o Duct. Seu navegador abre no Duct. Clique em Permitir.

OpenCode

  1. Adicione Duct a opencode.json: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Então entre: 
    opencode mcp auth duct
  3. Seu navegador abre no Duct. Clique em Permitir.

Claude, em claude.ai ou Claude Desktop

  1. Em claude.ai ou no Claude Desktop, abra Configurações → Conectores e escolha Adicionar conector personalizado.
  2. Nomeie-o Duct e cole o endereço: 
    https://api.getduct.ai/mcp
  3. Pressione Conectar. Duct abre no seu navegador. Clique em Permitir.

ChatGPT

  1. Nas configurações do ChatGPT, ative o modo de desenvolvedor.
  2. Adicione um conector com este endereço, e escolha OAuth para autenticação: 
    https://api.getduct.ai/mcp
  3. Duct abre no seu navegador. Clique em Permitir.

Outro agente? Se ele puder adicionar um servidor MCP remoto pelo seu endereço, dê a ele o mesmo. Se ele não conseguir entrar, use um token.

O que seu agente pode fazer

Ele lê e rascunha. Você decide.

Duct oferece três ferramentas ao seu agente hoje. Aprovar, aplicar e conectar permanecem com você, no Duct.

Seu agente pode
  • Liste seus projetos.
  • Leia um projeto.
  • Rascunhe a descrição, público e concorrentes de um projeto do seu repositório ou arquivos.
Ele nunca pode
  • Aprove ou aplique as alterações.
  • Conecte ferramentas.
  • Veja chaves ou credenciais.
  • Sobrescreva o que você digitou no Duct. Um rascunho apenas preenche espaços em branco ou substitui um rascunho anterior.

Toda alteração aparece na atividade do projeto.

Acesso

Todo agente está listado. Desconecte qualquer um.

Você vê cada agente conectado

No Duct, abra Configurações → Conecte seu agente de IA. Todos os agentes que você permitiu estão lá, e você pode desconectá-lo. Um agente desconectado para na sua próxima chamada.

Sem navegador? Use um token.

Para CI, uma máquina remota ou um agente sem precisar entrar. Crie um na mesma página de configurações, em "Sem navegador? Use um token.". Seu agente o envia como um cabeçalho:

Authorization: Bearer duct_mcp_…

No Claude Code:

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

Solução de problemas

Preso? Comece aqui.

Meu navegador nunca abriu

Inicie o login você mesmo: execute /mcp no Claude Code, codex mcp login duct no Codex, ou opencode mcp auth duct no OpenCode.

Ele diz que não conseguiu registrar, ou “não suporta registro dinâmico de cliente”

Atualize seu agente para a versão mais recente e tente novamente. Se ainda falhar, conecte-se com um token em vez disso.

Funcionou, e agora ele recebe um 401

Você o desconectou no Duct, ou seu acesso expirou após 90 dias sem uso. Entre novamente pelo seu agente.

Eu pedi para ele configurar o projeto e nada mudou

Um rascunho nunca sobrescreve o que você digitou no Duct. Ele apenas preenche campos em branco ou substitui um rascunho anterior. Verifique a página do projeto no Duct.

Eu hospedo o Duct

Use seu próprio endereço de API seguido por /mcp, no lugar de https://api.getduct.ai/mcp.
