O que o torna diferente

Um conector entrega linhas ao seu agente. O Duct entrega respostas.

Vários servidores vão passar seus dados para um agente. Depois, o agente precisa somar tudo, adivinhar o contexto e começar do zero a cada vez.

Feito para ser entregue a um agente

Ele faz o trabalho. Você fica com as chaves.

Agentes podem ser persuadidos pelo que leem. Portanto, as coisas que realmente importam nunca cabem a eles fazer, não importa o que você permita.

Sempre seu, no Duct
  • Aprovar ou aplicar uma alteração, publicar um post, conectar uma ferramenta. Nenhum agente pode, não importa o que você permita.
  • Suas senhas e chaves. Nenhum agente jamais vê nenhuma.
  • Um registro de tudo o que ele salva, em Atividade em seu próprio nome. Uma edição precisa de apenas um clique para ser desfeita.
  • Textos de uma página web, termo de busca ou post chegam até ele marcados como dados, nunca como instruções.
  • O botão de desligar. Desconecte em Configurações e ele para na próxima chamada.

Configuração por agente

Oito agentes. Um endereço.

Todo agente se conecta ao mesmo servidor. Escolha o seu para os passos exatos.

Claude Code

  1. No seu terminal, execute: 
    claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp
  2. No Claude Code, execute /mcp, selecione duct e escolha Autenticar.
  3. Seu navegador abre no Duct. Escolha o que ele pode fazer e clique em Permitir.
  4. Execute /mcp__duct__insights_brief ou peça o resumo desta semana.

Codex

  1. No seu terminal, execute: 
    codex mcp add duct --url https://mcp.getduct.ai/mcp
  2. Então entre: 
    codex mcp login duct
  3. Seu navegador abre no Duct. Escolha o que ele pode fazer e clique em Permitir.

Cursor

  1. Adicione Duct a ~/.cursor/mcp.json: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Nas configurações de MCP do Cursor, pressione o prompt de login no servidor duct.
  3. Seu navegador abre no Duct. Escolha o que ele pode fazer e clique em Permitir.

Gemini CLI

  1. Adicione o Duct ao ~/.gemini/settings.json: 
    {
  "mcpServers": {
    "duct": {
      "httpUrl": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Inicie o Gemini CLI e entre: 
    /mcp auth duct
  3. Seu navegador abre no Duct. Escolha o que ele pode fazer e clique em Permitir.
  4. Execute /insights_brief ou peça o resumo desta semana.

VS Code

  1. Abra a Paleta de Comandos e execute MCP: Adicionar Servidor.
  2. Escolha HTTP, cole o endereço e nomeie-o duct: 
    https://mcp.getduct.ai/mcp
  3. O VS Code pede para você entrar na primeira vez que usa o Duct. Seu navegador abre no Duct. Escolha o que ele pode fazer e clique em Permitir.

OpenCode

  1. Adicione Duct a opencode.json: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Então entre: 
    opencode mcp auth duct
  3. Seu navegador abre no Duct. Escolha o que ele pode fazer e clique em Permitir.

Claude, em claude.ai ou Claude Desktop

  1. Em claude.ai ou no Claude Desktop, abra Configurações → Conectores e escolha Adicionar conector personalizado.
  2. Nomeie-o Duct e cole o endereço: 
    https://mcp.getduct.ai/mcp
  3. Pressione Conectar. O Duct abre no seu navegador. Escolha o que ele pode fazer e clique em Permitir.

ChatGPT

  1. Nas configurações do ChatGPT, ative o modo de desenvolvedor.
  2. Adicione um conector com este endereço, e escolha OAuth para autenticação: 
    https://mcp.getduct.ai/mcp
  3. O Duct abre no seu navegador. Escolha o que ele pode fazer e clique em Permitir.

Outro agente? Se ele puder adicionar um servidor MCP remoto pelo seu endereço, dê a ele o mesmo. Se ele não conseguir entrar, use um token.

Todo agente está listado. Desconecte qualquer um.

Você vê cada agente conectado

No Duct, abra Configurações → Conectar seu agente de IA. Todos os agentes que você permitiu estão lá, com o que podem fazer e em quais projetos, e você pode desconectá-los. Um agente desconectado para na próxima chamada.

Sem navegador? Use um token.

Para CI, uma máquina remota ou um agente sem entrar. Crie um na mesma página de configurações, em Sem navegador? Use um token, com as mesmas opções. Seu agente o envia como cabeçalho:

Authorization: Bearer duct_mcp_…

No Claude Code:

claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

Perguntas

As perguntas das pessoas. E depois as correções.

Antes de conectar

Preciso de uma chave de API?

Não. Seu agente roda no plano que você já paga, e o Duct não chama nenhum modelo para isso. Uma chave salva serve apenas para imagens e para o que o Duct executa sem você, como um resumo agendado.

Quais das minhas ferramentas ele pode ler?

Stripe, Meta Ads, Mixpanel, GitHub, RevenueCat, Clarity, GrowthBook, Apple Search Ads, feeds RSS e o restante que você conecta no Duct. Google Analytics, Search Console, Google Ads e Tag Manager permanecem no próprio agente do Duct por enquanto, enquanto a política do Google para assistentes de IA externos é confirmada.

Pode alterar minha conta de anúncios?

Apenas se você ativar alterações propostas, e apenas como uma proposta. Fica aguardando na fila de revisão do Duct até você aprovar lá. Nenhum agente pode aprovar ou aplicar uma alteração.

O Duct vê minha conversa?

Não. O Duct vê as chamadas que seu agente faz a ele, como os dados solicitados e o motivo, nunca o restante do seu chat.

Um resumo será executado com o notebook fechado?

Não do seu agente. Resumos agendados rodam no Duct com uma chave salva, porque o agente de ninguém roda às 3h. O que seu agente escreve vai para a mesma biblioteca.

O que é insights_brief?

O playbook do Duct para um resumo, como um comando de barra: /mcp__duct__insights_brief no Claude Code, /insights_brief no Gemini CLI. Em qualquer outro agente, peça o resumo desta semana e ele chama o mesmo playbook.

Se algo der errado

Meu navegador nunca abriu

Inicie o login você mesmo: execute /mcp no Claude Code, codex mcp login duct no Codex, /mcp auth duct no Gemini CLI ou opencode mcp auth duct no OpenCode.

Ele diz que não conseguiu registrar, ou “não suporta registro dinâmico de cliente”

Atualize seu agente para a versão mais recente e tente novamente. Se ainda falhar, conecte-se com um token em vez disso.

Funcionou, e agora ele recebe um 401

Você o desconectou no Duct, ou seu acesso expirou após 90 dias sem uso. Entre novamente pelo seu agente.

Uma ferramenta que eu esperava não está aqui

Seu agente só vê o que você permitiu quando ele entrou. Desconecte-o no Duct, conecte novamente e escolha Trabalhe ao meu lado.

Eu pedi para ele configurar o projeto e nada mudou

Um rascunho nunca sobrescreve o que você digitou no Duct. Ele apenas preenche campos em branco ou substitui um rascunho anterior. Verifique a página do projeto no Duct.

Eu hospedo o Duct

Use o seu próprio endereço de API seguido de /mcp, em vez de https://mcp.getduct.ai/mcp.
