O agente propõe. Você aprova.

O Duct pode preparar uma alteração nos seus anúncios ou análises. Nenhuma ferramenta permite que ele aprove uma, então ele não pode ser convencido a fazer isso.

Qualquer ação destrutiva aguarda seu clique, em qualquer configuração.

Uma lista curta de alterações reversíveis pode ser aplicada por conta própria, e apenas se você ativar essa opção.

Alugue o framework de agentes. Nunca se case com ele.

Frameworks de agentes mudam toda semana. Os prompts, ferramentas e pontuações do Duct são Python puro, e um teste falha se uma importação de framework aparecer fora dos poucos arquivos adaptadores.

Abstraia no segundo uso.

Uma implementação é um palpite. Duas são um fato. Os adaptadores compartilhados foram extraídos quando um segundo agente precisou deles, e a allowlist diz qual deles.

Uma chave de API não é uma permissão.

A chave do app vai para o navegador, então ela prova qual app está chamando, nunca quem. Cada rota de projeto verifica se você é um membro, e um desconhecido recebe um 404.

Um teste percorre todas as rotas e falha em uma sem usuário conectado, a menos que haja um motivo por escrito ao lado dela.

Suas chaves, sua escolha de modelo.

Traga uma chave da Anthropic, OpenAI, Google, xAI ou OpenRouter, ou execute um modelo local. Você escolhe três modelos; o Duct decide qual tarefa precisa de qual.

O app para desktop guarda suas chaves no chaveiro do SO. Para não usar nenhum servidor do Duct, a versão auto-hospedada executa todo o backend na sua máquina.

Os comentários trazem o porquê.

Um comentário que repete a linha abaixo dele ensina as pessoas a ignorar comentários. Os que valem a pena ser escritos nomeiam a ameaça, a falha ou a opção perdedora.

No código que os agentes ajudam a escrever, esse raciocínio é o que serve de base para verificar a próxima alteração. O STYLE.md cita este como o modelo.

Pull requests escritos por agentes são bem-vindos.

O modelo pergunta onde um agente ajudou, para que o revisor saiba onde olhar com mais atenção. Nada é rejeitado por marcar essa opção.

Discorda de algum? Fale em público.

Cada um destes é um padrão com um motivo. Se o motivo estiver errado, o motivo deve mudar.
