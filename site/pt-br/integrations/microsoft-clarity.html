Conhecimento

O que o Duct já sabe sobre o Clarity

  1. 01

    O Clarity mantém três dias.

    Sua API retorna apenas os últimos um a três dias, então é uma verificação de saúde, não histórico. O Duct o lê para o que está acontecendo agora, e diariamente quando algo precisa ser monitorado.

  2. 02

    Dez chamadas por dia, fixo.

    O Clarity permite dez requisições de API por projeto por dia e uma leitura do Duct custa duas, então o Duct nunca faz polling. Atingir o limite significa amanhã, não uma nova tentativa.

  3. 03

    Bots estão nas sessões.

    O Clarity conta sessões de bot com as demais. O Duct as remove antes de calcular qualquer taxa.

  4. 04

    Compare por participação, não por contagem.

    Um valor de atrito é a parcela de sessões que tiveram pelo menos um. Duct compara páginas por essa parcela, para que uma página movimentada não pareça pior por estar movimentada.

Configuração

Conecte o Clarity em três passos

  1. 1

    No Clarity, abra Configurações, depois Exportação de Dados, e gere um token de API.

  2. 2

    Crie-o no projeto que o Duct deve ler: o token é o projeto, sem ID ao lado.

  3. 3

    No Duct, abra Conexões, escolha Microsoft Clarity e cole o token.

Somente leitura: um token de exportação só pode ler, e o Duct não tem operação de alteração no Clarity.

Chaves e tokens são armazenados criptografados pela API hospedada do Duct, nunca no seu navegador, e você pode remover uma conexão a qualquer momento. Uma versão auto-hospedada os mantém na sua própria máquina.

FAQ

Clarity, respondido

O Duct pode ver gravações de sessão?

Não. Ele lê os números exportados por página do Clarity, não gravações ou mapas de calor.

Por que apenas os últimos três dias?

Isso é tudo que a API do Clarity retorna. O Duct o trata como um sinal de saúde em tempo real e, quando um problema precisa ser acompanhado, o lê diariamente.

O Duct pode alterar algo no Clarity?

Não. Ele não tem operação de alteração no Clarity. Ele pode dizer qual página corrigir.

É gratuito?

Sim. Duct é gratuito com suas próprias chaves de modelo ou o plano ChatGPT que você já tem, e o núcleo tem licença MIT. Um plano pago posteriormente agrupará os modelos; nada que é aberto hoje passará a ser pago. O que vai custar dinheiro.
