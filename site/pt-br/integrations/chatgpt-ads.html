Conhecimento

O que o Duct já sabe sobre o ChatGPT Ads

  1. 01

    A API de Anúncios não pode ver conversões.

    Suas métricas são impressões, cliques, gastos, CTR, CPC e CPM. As conversões do pixel aparecem apenas no Ads Manager, então o Duct nunca considera o canal bom apenas pelo CPC. Ele verifica o Stripe.

  2. 02

    Duas unidades de um fornecedor.

    Insights reportam gastos como um decimal (18.42); o pixel reporta centavos (1499). Misturá-los é um erro de 100×, então o Duct converte antes de comparar.

  3. 03

    Uma chave, uma conta de anúncio.

    Uma chave da API de anúncios acessa exatamente uma conta de anúncios. Duct lê qual delas primeiro, então uma chave da conta errada informa isso em vez de parecer vazia.

  4. 04

    Só o faturador sabe.

    Toda plataforma de anúncios informa conversões que atribui a si mesma. O Duct as reconcilia com o Stripe, nunca umas contra as outras.

Configuração

Conecte o ChatGPT Ads em três passos

  1. 1

    No OpenAI Ads Manager, crie uma chave de API de Anúncios para a conta de anúncio que você quer ler.

  2. 2

    No Duct, abra Conexões, escolha OpenAI Ads e cole a chave.

  3. 3

    O Duct mostra a qual conta de anúncio a chave pertence, depois lê suas campanhas e totais diários.

Uma chave da API de anúncios está vinculada a uma conta de anúncios, e a OpenAI concede acesso à API por conta enquanto a API está em beta. Duct usa a chave apenas para ler; ele não tem operação de alteração para ChatGPT Ads.

Chaves e tokens são armazenados criptografados pela API hospedada do Duct, nunca no seu navegador, e você pode remover uma conexão a qualquer momento. Uma versão auto-hospedada os mantém na sua própria máquina.

FAQ

ChatGPT Ads, respondido

Duct consegue ver as conversões de ChatGPT Ads?

Não, porque a API do OpenAI Ads não os informa; as conversões do pixel aparecem apenas no Ads Manager. O Duct mede o canal em relação ao que o Stripe liquidou e o que o GA4 viu, que é o número que decide o orçamento de qualquer forma.

O Duct altera minhas campanhas do ChatGPT Ads?

Não. O conector é somente leitura. O Duct pode recomendar mover o orçamento entre campanhas ou canais; você faz a alteração no Ads Manager.

ChatGPT Ads e OpenAI Ads são a mesma coisa?

Sim. OpenAI vende os anúncios que rodam no ChatGPT através do seu Ads Manager e Ads API. O app Duct lista o conector como OpenAI Ads.

É gratuito?

Sim. Duct é gratuito com suas próprias chaves de modelo ou o plano ChatGPT que você já tem, e o núcleo tem licença MIT. Um plano pago posteriormente agrupará os modelos; nada que é aberto hoje passará a ser pago. O que vai custar dinheiro.
