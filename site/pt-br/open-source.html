Acesso de leitura a tudo é muito pedir.

Duct lê seus anúncios, análises, receita e replays de sessão juntos. Uma ferramenta com essa visão não deve ser uma caixa preta. Cada chamada de API e cada prompt está no repositório, legível antes de você conectar qualquer coisa.

O agente pode propor uma alteração e visualizá-la. Ele não tem ferramenta para aprovar ou aplicar uma; esse é o seu botão, e o modelo nunca o vê. A doutrina vincula cada regra ao arquivo que a aplica.

Execute você mesmo

Clone-o. Adicione uma chave. Inicie ambas as metades.

O backend é FastAPI, o app é Next.js, e um único Makefile gerencia ambos. Adicione uma chave de provedor de modelo ao arquivo .env e você estará lendo suas próprias ferramentas da sua própria máquina em minutos.

O README é a fonte da verdade para a configuração, e também cobre a compilação para desktop com o backend empacotado dentro: SQLite no disco, apenas loopback, sem conta. O CONTRIBUTING.md lista as verificações que o CI executa.

terminal 
$ git clone https://github.com/5hirish/duct.git && cd duct
$ make setup
$ cp backend/.env.example backend/.env.local   # add one model provider key
$ make serve-backend                            # then, in a second terminal:
$ make serve-app

O que vai custar dinheiro

Grátis com suas próprias chaves. Sempre.

A licença MIT não é uma avaliação. Os agentes, os conectores e o portão de aprovação são o produto, e estão no repositório. Execute-os com suas próprias chaves de modelo, ou com o plano ChatGPT que você já paga, e você não nos deve nada.

O que virá depois é um plano pago que agrupa os modelos, para que uma equipe possa usar o Duct sem que ninguém precise de uma chave de API, além do serviço hospedado com o qual o app para desktop já se comunica. Nada que é aberto hoje passará para trás desse plano. Se isso mudar, esta página informará antes que o código o faça.

Perguntas

As que as pessoas realmente perguntam

Duct é realmente grátis?

Sim. Duct é licenciado MIT e grátis com suas próprias chaves de modelo, e isso não muda. Você paga seu provedor de modelo diretamente, ou entra com o plano ChatGPT que você já tem. Um plano pago posteriormente agrupa o acesso ao modelo para equipes que preferem não manter chaves; nada que esteja aberto hoje se move para trás dele.

Posso executar o Duct sem uma conta?

Sim. Clone o repositório, execute make setup, adicione uma chave de provedor de modelo e inicie o backend e o app. Tudo permanece na sua máquina ou no seu servidor, e nenhuma conta com Duct está envolvida.

Posso usar o Duct comercialmente ou fazer um fork?

Sim. A licença MIT permite uso comercial, modificação e redistribuição. As únicas exceções são a documentação de terceiros em docs/guides e o nome e a marca Duct.

Como eu contribuo?

Comece com CONTRIBUTING.md. Problemas e discussões estão no GitHub, o roteiro é um quadro de projeto público, e contribuições escritas por agentes são bem-vindas, desde que o pull request diga onde um agente ajudou.
