Use Duct from your agent. No token to copy.

Paste one address into your agent, click Allow once, and it can read and draft your Duct projects.

https://api.getduct.ai/mcp

Setup for

  • Claude Code
  • Codex
  • Cursor
  • VS Code
  • OpenCode
  • Claude
  • ChatGPT

Pick your agent. Paste one line.

Claude Code

  1. Run this in your terminal: 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. In Claude Code, run /mcp, pick duct, choose Authenticate and click Allow.

Codex

  1. Run these in your terminal: 
    codex mcp add duct --url https://api.getduct.ai/mcp
    codex mcp login duct
  2. Your browser opens on Duct. Click Allow.

Cursor

  1. Add this to ~/.cursor/mcp.json: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. In Cursor's MCP settings, sign in on duct and click Allow.

VS Code

  1. From the Command Palette, run MCP: Add Server, choose HTTP and paste: 
    https://api.getduct.ai/mcp
  2. Name it duct. The first time it uses Duct, click Allow in your browser.

OpenCode

  1. Run these in your terminal: 
    opencode mcp add duct --global --url https://api.getduct.ai/mcp
    opencode mcp auth duct
  2. Your browser opens on Duct. Click Allow.

Claude, on claude.ai or Claude Desktop

  1. In Settings → Connectors, choose Add custom connector, name it Duct and paste: 
    https://api.getduct.ai/mcp
  2. Press Connect, then click Allow.

ChatGPT

  1. In ChatGPT's settings, turn on developer mode.
  2. Add a connector with OAuth and this address: 
    https://api.getduct.ai/mcp
  3. Your browser opens on Duct. Click Allow.

Another agent? Any that adds a remote MCP server by address works. If it can't sign in, use a token.

For CI or a remote machine. Create one on the same settings page; your agent sends it as a header.

Authorization: Bearer duct_mcp_…

In Claude Code:

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

Stuck? Start here.

My browser never opened

Start the sign-in yourself: run /mcp in Claude Code, codex mcp login duct in Codex, or opencode mcp auth duct in OpenCode.

It says it couldn't register, or “does not support dynamic client registration”

Update your agent to its latest version and try again. If it still fails, connect with a token instead.

It worked, and now it gets a 401

You disconnected it in Duct, or its sign-in lapsed after 90 days without use. Sign in again from your agent.

I asked it to set up the project and nothing changed

A draft never overwrites what you typed in Duct. It only fills blank fields or replaces an earlier draft. To change a field you set, ask for that edit by name.

I host Duct myself

Use your own API address followed by /mcp, in place of https://api.getduct.ai/mcp.

Paste it in your agent. Click Allow.
