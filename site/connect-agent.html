Setup by agent

Eight agents. One address.

Every agent connects to the same server. Pick yours for the exact steps.

Claude Code

  1. In your terminal, run: 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. In Claude Code, run /mcp, pick duct and choose Authenticate.
  3. Your browser opens on Duct. Choose what it can do, then click Allow.
  4. Run /mcp__duct__insights_brief, or ask for this week's brief.

Codex

  1. In your terminal, run: 
    codex mcp add duct --url https://api.getduct.ai/mcp
  2. Then sign in: 
    codex mcp login duct
  3. Your browser opens on Duct. Choose what it can do, then click Allow.

Cursor

  1. Add Duct to ~/.cursor/mcp.json: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. In Cursor's MCP settings, press the login prompt on the duct server.
  3. Your browser opens on Duct. Choose what it can do, then click Allow.

Gemini CLI

  1. Add Duct to ~/.gemini/settings.json: 
    {
  "mcpServers": {
    "duct": {
      "httpUrl": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Start Gemini CLI and sign in: 
    /mcp auth duct
  3. Your browser opens on Duct. Choose what it can do, then click Allow.
  4. Run /insights_brief, or ask for this week's brief.

VS Code

  1. Open the Command Palette and run MCP: Add Server.
  2. Choose HTTP, paste the address and name it duct: 
    https://api.getduct.ai/mcp
  3. VS Code asks you to sign in the first time it uses Duct. Your browser opens on Duct. Choose what it can do, then click Allow.

OpenCode

  1. Add Duct to opencode.json: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Then sign in: 
    opencode mcp auth duct
  3. Your browser opens on Duct. Choose what it can do, then click Allow.

Claude, on claude.ai or Claude Desktop

  1. On claude.ai or in Claude Desktop, open Settings → Connectors and choose Add custom connector.
  2. Name it Duct and paste the address: 
    https://api.getduct.ai/mcp
  3. Press Connect. Duct opens in your browser. Choose what it can do, then click Allow.

ChatGPT

  1. In ChatGPT's settings, turn on developer mode.
  2. Add a connector with this address, and choose OAuth for authentication: 
    https://api.getduct.ai/mcp
  3. Duct opens in your browser. Choose what it can do, then click Allow.

Another agent? If it can add a remote MCP server by its address, give it the same one. If it can't sign in, use a token.

Questions

The ones people ask. Then the fixes.

Before you connect

Do I need an API key?

No. Your agent runs on the plan you already pay for, and Duct calls no model for it. A saved key is only for images, and for what Duct runs without you, like a scheduled brief.

Which of my tools can it read?

Stripe, Meta Ads, Mixpanel, GitHub, RevenueCat, Clarity, GrowthBook, Apple Search Ads, RSS feeds and the rest you connect in Duct. Google Analytics, Search Console, Google Ads and Tag Manager stay inside Duct's own agent for now, while Google's policy for outside AI assistants is confirmed.

Can it change my ad account?

Only if you turn on proposed changes, and only as a proposal. It waits in Duct's review queue until you approve it there. No agent can approve or apply a change.

Does Duct see my conversation?

No. Duct sees the calls your agent makes to it, like the data it asked for and why, never the rest of your chat.

Will a brief run while my laptop is closed?

Not from your agent. Scheduled briefs run in Duct on a saved key, because nobody's agent runs at 3am. What your agent writes lands in the same library.

What is insights_brief?

Duct's playbook for a brief, as a slash command: /mcp__duct__insights_brief in Claude Code, /insights_brief in Gemini CLI. In any other agent, ask for this week's brief and it calls the same playbook.

If something goes wrong

My browser never opened

Start the sign-in yourself: run /mcp in Claude Code, codex mcp login duct in Codex, /mcp auth duct in Gemini CLI, or opencode mcp auth duct in OpenCode.

It says it couldn't register, or “does not support dynamic client registration”

Update your agent to its latest version and try again. If it still fails, connect with a token instead.

It worked, and now it gets a 401

You disconnected it in Duct, or its sign-in lapsed after 90 days without use. Sign in again from your agent.

A tool I expected isn't there

Your agent only sees what you allowed when it signed in. Disconnect it in Duct, connect again, and choose Work alongside me.

I asked it to set up the project and nothing changed

A draft never overwrites what you typed in Duct. It only fills blank fields or replaces an earlier draft. Check the project page in Duct.

I host Duct myself

Use your own API address followed by /mcp, in place of https://api.getduct.ai/mcp.
