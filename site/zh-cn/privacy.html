隐私政策

最后更新：2026 年 11 月 5 日

Alleviate Lab（“我们”）运营 Duct（getduct.ai），这是一个跨工具智能平台，它连接你的广告、分析、产品和搜索工具，综合分析它们之间的变化，并且——仅在你批准特定变更时——将该变更应用回已连接的工具。本隐私政策解释了我们收集什么、为什么收集、与谁共享、保留多久以及如何删除。

Duct 仅通过官方 Google API 访问 Google 用户数据，并且仅限于你明确连接的 Google 账户和属性。在你完成 Google 的同意界面之前，不会访问任何内容，下方每个范围都用于其旁所述目的。

2. Duct 代表你进行的变更

上述某些范围允许写入。我们希望对此进行精确说明，因为这是 Duct 触及你实时账户的部分：

  • 不会自动写入任何内容。Duct 会提出一个变更集，向你展示每个单独变更的确切前后对比，并且在你明确在应用中批准之前，不会应用任何内容。
  • 批准是针对每个变更集，而非一揽子。 批准一项变更不授权未来的变更。
  • 变更会被记录，并且在底层 API 允许的情况下可逆。 每项已应用的变更都会写入你的项目审计日志。
  • 报告功能无需写入权限即可工作。如果你偏好只读，请连接只读范围并拒绝其余权限；Duct 的报告仍然可以运行。

3. 我们如何使用 Google 用户数据

  • 身份验证： 用于验证你的身份并保持你的会话
  • 报告和洞察：从你连接的资产中获取数据，并生成你请求的简报、警报和审计
  • 已批准的变更： 将你批准的特定变更应用到你选择的已连接账户
  • 支持：诊断你向我们报告的问题，使用所需的最少数据

我们仅使用 Google 用户数据来提供和改进这些面向用户的功能。我们不将其用于任何其他目的。

4. Google 用户数据的有限使用

Duct 使用和传输从 Google API 接收的信息到任何其他应用时，将遵守 Google API 服务用户数据政策，包括有限使用要求。

具体来说，我们不会：

  • 使用或传输 Google 用户数据用于投放任何类型的广告，包括定向、个性化、重定向或基于兴趣的广告
  • 出售、出租或转让 Google 用户数据给数据经纪人、信息转售商或任何第三方用于其自身目的
  • 使用 Google 用户数据来评估信用度或用于贷款目的
  • 使用 Google 用户数据来构建或丰富独立的数据库或用户画像
  • 使用 Google 用户数据开发、改进或训练通用或非个性化 AI 或机器学习模型
  • 允许人类读取 Google 用户数据，除非你已就特定问题明确同意，或出于安全目的或遵守适用法律的需要，或数据已聚合和匿名化。

网络应用中的会话回放和点击分析从不记录 Google 用户数据：屏幕上的所有文本在发送之前都会在你的浏览器中被遮盖（第 11 节）。

5. 你连接的其他数据源

Google 是 Duct 可以连接的多个来源之一。每个来源都是可选的，由你单独连接，并通过你授权的凭据访问提供商的官方 API。Duct 读取构建报告所需的指标，并且只写入你明确批准的变更。

  • 广告： Meta Ads、Apple Search Ads、OpenAI Ads
  • 产品和行为分析：Mixpanel, Microsoft Clarity
  • 实验：GrowthBook
  • 收入和账单：Stripe, RevenueCat
  • CRM： HubSpot
  • 社交发布和分析：PostBridge，它会连接你授权的社交账户（TikTok、Instagram、YouTube、LinkedIn、X、Pinterest、Facebook、Google Business Profile）

本政策中的承诺——不销售你的数据、不用于广告、不用于模型训练、按请求删除——适用于来自这些来源的数据，与适用于 Google 用户数据的方式完全相同。

6. Content Studio：上传和发布

如果你使用 Duct 的内容功能：

  • 你上传的文件（图片、视频、品牌资产）会被存储，以便可以附加到草稿和已发布的帖子中。
  • 生成的媒体。在 Duct 中创建的图片和视频由第三方生成式 AI 服务生成，这些服务会接收你提供的提示和任何参考图片。

  • 公开研究数据。Duct 可以从社交平台检索公开可用的内容和指标，以提供建议。这是公开数据，而不是关于你或你的受众的个人数据。

请勿上传你无权使用的材料，或包含他人个人数据超出你的帖子所需的文件。

7. Duct 桌面应用

桌面应用是一个原生窗口，围绕着你在浏览器中使用的同一个 Duct。有必要精确说明这意味着什么，因为“桌面应用”听起来像是“所有东西都留在这里”，但这并非我们所交付的：

  • 我们分发的应用与我们的服务器通信。它不包含 Duct 后端自身的副本。你的项目、简报、智能体记忆、活动日志、上传内容和连接器授权都由我们存储，与你在浏览器中使用 Duct 时完全相同——这也是为什么你可以在第二台电脑上登录并找到你的工作。第 12 至 14 节涵盖我们如何存储、共享和删除它。
  • 你的 AI 提供商密钥保留在你的机器上。 它们存储在你的操作系统密钥链中，仅在任务需要运行时才随请求发送。我们从不存储它们，浏览器版本提供的保存密钥选项在桌面应用中已特意关闭。
  • 登录和连接器授权会打开你的系统浏览器而不是嵌入式窗口，这样你可以保留浏览器自身的保护，并且返回应用的链接中绝不会携带任何凭据。
  • 桌面应用从不询问你的 Cookie。 它的使用事件和崩溃报告会发送到 PostHog，在桌面应用中，PostHog 将所有内容保存在内存中，不会写入你的机器，因此 PostHog 的 Cookie 不存在。在你刚打开的应用前出现同意栏，不值得为此打断任何人。应用的窗口确实会加载我们的网页应用，所以 Google Analytics 也会在那里运行，设置第 11 节中列出的 Google Cookie，并且不受下方开关的影响。
  • 在我们分发的应用中，崩溃报告和使用数据默认开启，偏好设置中的一个开关可以关闭两者。 一旦你更改了设置，你的选择将被保留，默认设置将不再适用。崩溃报告包含导致错误的错误信息和堆栈跟踪；使用数据是你打开的屏幕和功能——绝不包含你的提供商 API 密钥、你的数据或你生成的任何内容。如果你已登录，两者都包含你的账户 ID。如果你自行构建 Duct，两者默认关闭，因为在这种情况下并非由我们运行。
  • 桌面应用从不记录你的会话回放。 会话回放（第 11 节）仅存在于我们的网站和浏览器中的网页应用中。
  • 更新检查 会联系我们的发布主机，询问是否存在新版本。此请求会透露你的 IP 地址和你正在运行的版本。
  • 你可以选择自行运行整个系统。 源代码是公开的，可以在应用内部构建后端，或托管在你自己的服务器上。这样我们不保留任何数据，此政策也无需描述任何内容——请参阅第 16 节。

8. 自带 AI 提供商密钥

你可以提供你自己的 AI 提供商 API 密钥，而不是使用 Duct 的：

  • 在桌面应用中，密钥存储在你的操作系统的钥匙串中。它们随请求发送，以便你请求的任务可以运行，我们从不存储它们；在那里，与我们一起保存密钥的选项是关闭的。
  • 在网页应用中，你粘贴的密钥会保留在该浏览器会话中，并随每个请求发送。如果你选择保存它，以便不必再次粘贴，它会在静态时加密，仅在代表你发出请求时解密，绝不会由我们的 API 返回，也绝不会写入日志。你可以随时删除它。
  • 当你使用自己的密钥时，你的使用量将由该提供商在你的账户下计费，并受该提供商的条款和隐私政策约束。
  • 提供商的数据设置由你配置。 提供商是否保留或训练其接收的数据，由你与该提供商账户的政策决定，而非我们——请参阅第 12 节中关于路由的说明。

11. 我们收集的其他信息

使用数据

我们收集产品分析数据——访问的页面、使用的功能、你的点击、页面加载速度——以了解哪些页面促成注册以及 Duct 在何处阻碍了你。在我们的网站和浏览器中的网络应用中，这通过 PostHog 运行，并遵循下方描述的 Cookie 选择。

我们还使用通过 Google Tag Manager 加载的 Google Analytics 来统计访问量并查看其来源。它在我们的网站、网页应用和桌面应用的窗口中运行。它不遵循下述 Cookie 选择：它会在每个页面加载，在您回答之前和拒绝之后。Google 会收到页面的完整地址、您的来源、您的浏览器和设备、您的 IP 地址（用于估算您的位置）以及来自下方列出的 Cookie 的标识符。这些标签还会将访问数据发送到 Google 的广告服务，包括用于构建广告受众的服务。我们目前没有运行 Google Ads。如果您不希望这样，Google 提供了一个浏览器插件，可让您选择退出 Google Analytics。

PostHog 还会记录会话回放：对页面和你点击位置的重构，以便我们查看访问出了什么问题。回放隐藏的内容在你的浏览器中，在任何数据离开浏览器之前就已经隐藏了：

  • 在我们的网站上，你输入到字段中的所有内容。
  • 在网页应用中，你输入的所有内容，以及屏幕上的所有文本、图片、嵌入文档、图表和视频。应用的重放会显示布局、你的点击和访问路径，但从不显示页面上的数据。当 PostHog 统计应用中的点击时，它会记录点击了哪个元素，而不是元素上的文本。

回放从不包含你的浏览器控制台日志。我们不记录按键或表单内容。

当你登录时，我们的服务器也会记录你在 Duct 中执行的操作，例如启动内容计划、批准或应用变更，并关联你的账户 ID。你的 PostHog 个人资料会保存你的电子邮件地址和姓名，以便我们可以在你遇到问题时联系你。

AI 模型调用

对于 Duct 对 AI 模型进行的每次调用，我们只记录元数据：模型、token 数量、耗时、成本以及任何错误。绝不记录提示或响应文本。

Cookie 和类似技术

我们请求的选择涵盖 PostHog 的分析 Cookie。如果你在 EEA、英国或瑞士，我们会在 PostHog 设置任何内容之前征求你的同意。在其他地区，它默认开启，你可以随时关闭：我们页脚中的 Cookie 设置 链接，以及应用内的账户菜单，会在每个页面重新打开选择。

Google Analytics 不属于该选择范围。无论你身在何处、做出何种选择，其下方的 cookie 都会在页面加载时设置。

拒绝意味着 PostHog 完全不加载，而非以受限模式加载。如果你在之前接受后选择拒绝，我们将停止 PostHog，删除其 Cookie 及其在浏览器存储中的副本，并重新加载页面。Google Analytics 无论如何都会继续运行。

诊断

当 web 应用出现故障时，它会向 PostHog 发送一份错误报告：堆栈跟踪、你的浏览器、不带查询字符串的页面路径，以及（如果你已登录）你的 account ID。web 应用还会发送每个页面加载和响应所需的时间（web vitals），这仅是时间信息。无论你是否接受 analytics cookies，web 应用都会发送错误报告和页面时间信息，因为它们不会在你的设备上存储任何内容：它们仅在该页面内存中保留，当你离开页面时即消失。在我们的网站上，这两者都属于分析的一部分，并遵循你的 cookie 选择。

我们的服务器以同样的方式向 PostHog 报告其自身错误，并附带几行记录服务器启动和停止时间的日志。我们配置错误报告以避免捕获 Google 用户数据，但报告可能偶然包含一个标识符，例如媒体资源 ID。

活动和智能体记忆

Duct 记录项目中重要操作的活动日志，并存储其智能体从你的数据中提取的持久性笔记（例如，重复的季节性模式），以便报告随时间推移而改进。两者都限定在你的项目范围内，对你可见，并随项目删除而删除。

本地存储的数据

我们在你的浏览器本地存储中存储一个身份验证令牌，以保持你登录。它包含你的姓名、电子邮件和个人资料图片，并于 7 天后过期。

当连接的源数据发送给 AI 模型提供商时，它仅用于生成你请求的输出。我们绝不会将其用于训练模型，也绝不允许任何提供商代表我们这样做。 Anthropic、OpenAI 和 Google 均在 API 条款下使用，这些条款默认排除提交数据用于训练。

OpenRouter 是一个路由器，而不是模型提供商，需要特别说明。它会将请求转发到路由配置选择的任何底层提供商，这些提供商在是否记录或训练其接收到的数据方面有所不同。当你提供自己的 OpenRouter 密钥时，该路由配置属于你：请求的保留和训练行为受你的 OpenRouter 账户上设置的数据策略管辖，你应该将其设置为符合你所需承诺的策略。我们建议在连接密钥之前启用 OpenRouter 的零日志和无训练数据策略。无论采用哪种路由，Duct 都不会使用你的数据进行训练。

我们也可能在法律要求时披露数据，并在合并或收购的情况下向继承实体披露数据，届时本政策将继续适用，直到你收到另行通知。

13. 数据安全

  • OAuth 令牌和保存的提供商密钥在静态时加密使用 Fernet 对称加密，按用户存储在服务器端，并且绝不暴露给浏览器
  • 所有传输中的数据均通过 HTTPS/TLS 加密
  • 访问项目数据需要身份验证和该项目的验证成员身份；非成员无法读取其他项目的数据
  • 我们遵循内部数据访问的最小权限原则。
