检查内容

六个领域，按发布可能造成的损失加权。

无法衡量的发布毫无参考价值，因此测量权重最高。发布当天被置顶评论的往往是与代码相悖的说辞，因此陈述紧随其后。

每个维度初始均为 100 分。FAIL 扣 25 分，WARN 扣 10 分。无法检查的项目不扣分并标为未验证，因此缺少仓库只会降低置信度，不会拉低分数。

  • 85–100 就绪
  • 70–84 修复后就绪
  • 55–69 待改进
  • 低于 55 未就绪

三项修复

仅有两项发现达到处理标准。其余皆为细节打磨。

  1. 统计未获用户同意因而遗漏的下载量。

    在欧洲经济区、英国和瑞士，分析脚本仅在点击接受后加载，而对于忽略横幅的访客，download_started 会在队列中等待且永远不会发送。发布当天来自欧洲的下载量统计将会偏低。

    影响 2 · 难度 1 · 发现来源：代码仓库 · site/assets/duct.js:364

    修复方式：无需代码。在发布当天读取 GitHub 上的 Release 下载量作为基准底数，并与 download_started 进行比对。

无需账号

无需注册，无需 API 密钥，无需登录 Duct。它直接使用智能体自带的网络和 Shell 工具，绝不会在任何地方注册、登录或提交表单。

不会向 Duct 发送任何内容

该技能是指令集，而非服务。你的网站和代码仅由你的智能体读取，绝不会传到别处。它绝不会打开 .env 或密钥文件。

未经确认不作更改

它只写入一个文件，即它的报告。每项修复都先展示 Diff，只有经你确认后才会应用。它绝不会提交、推送或部署。

常见问题

在你安装之前。

支持哪些智能体？

支持开源 skills CLI 可安装的任何智能体：包括 Claude Code、Codex、Cursor、OpenCode、Gemini CLI、GitHub Copilot、Windsurf 和 Zed。该技能是符合 Agent Skills 格式的单个 SKILL.md 文件夹，因此支持该格式的智能体无需安装器即可直接使用。

它会把我的网站或代码发送给 Duct 吗？

不会。此技能是一组由你的智能体使用其自带网络和 Shell 工具执行的指令。流程中没有 Duct 服务器，无需账号，也没有 API 密钥。你的智能体读取的内容只会发送到它一贯请求的目标：你已经在使用的模型。

它会修改我的代码吗？

未经确认不会更改。它自行写入的唯一文件是它的报告 duct-launch-check.md。每项修复都会依次以 Diff 和询问的形式呈现。它绝不会提交、推送或部署，也绝不会打开 .env 或密钥文件。

我需要打开代码仓库吗？

不需要，但有代码仓库效果更好。没有代码时，它仅检查上线页面，大多数衡量领域会返回未验证而非失败。页面审计无法发现的问题（例如下载未发送事件）均来自于代码仓库。

它与 SEO 审计有何不同？

SEO 审计只读取 HTML。launch-check 还会读取背后的代码，并对照产品实际功能核对页面承诺。搜索只是六个维度之一。如需包含关键词聚类和竞品分析的完整抓取，请运行 Duct 的免费 SEO 审计。

费用是多少，耗时多久？

该技能免费且采用 MIT 许可证。它在你智能体自身的模型上运行，因此一次检查的成本仅取决于你的智能体阅读 10 个页面和部分代码仓库所消耗的费用。它最多检查 10 个页面，目标是在 10 分钟内完成。

安装器会追踪任何数据吗？

skills CLI 是开源的且不归我们所有，它会为 skills.sh 排行榜匿名统计安装量。在运行前设置 DISABLE_TELEMETRY=1 或 DO_NOT_TRACK=1 即可将其关闭。技能本身不会向任何地方发送数据。

如何更新或移除它？

npx skills update 可更新至最新版本，npx skills remove launch-check 可将其移除。技能会安装到当前运行命令的项目中；添加 -g 可在所有项目中可用。CLI 需要 Node.js 22.20 或更高版本。
