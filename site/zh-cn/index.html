常见问题

五个诚实的回答

Duct 是什么？

Duct AI 是一个开源 AI 营销智能体。它连接你的产品、营销和收入工具，跨工具回答问题，提出变更建议并在你批准后应用。它作为桌面应用在 macOS、Windows 和 Linux 上运行。

免费吗？

是的。核心代码采用 MIT 许可，并将保持不变。你直接向模型提供商付费，或者使用你已有的 ChatGPT 计划登录。托管团队计划稍后推出；核心代码保持开源。

它会未经允许更改我的账户吗？

不。报告功能仅限只读访问。变更会连同其影响范围一起提出，并且只有在你按下“应用”后才会应用。模型可调用的列表中没有批准工具，因此它无法被说服应用任何内容。破坏性变更会被标记；任何超出安全限制的都会在你查看之前被阻止。Doctrine 页面链接了强制执行此规则的文件。

它连接哪些工具？

Google Ads、Meta Ads、Apple Search Ads、OpenAI Ads、GA4、Search Console、Tag Manager、Mixpanel、Microsoft Clarity、GrowthBook、Stripe 和 RevenueCat，HubSpot 紧随其后。四个 Google 工具通过 OAuth 连接；其余的只需粘贴一次密钥。无需手动导出任何内容。

我的密钥和数据存储在哪里？

模型密钥保留在你的操作系统的钥匙串中，并且只在作业运行时随请求传输。连接器授权由托管 API 加密存储。桌面应用是该 API 的一个轻量级外壳；自托管版本则在你的机器上运行所有内容。Duct 的命名由来在关于页面。
