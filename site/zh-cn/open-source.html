终端
$ git clone https://github.com/5hirish/duct.git && cd duct
$ make setup
$ cp backend/.env.example backend/.env.local   # add one model provider key
$ make serve-backend                            # then, in a second terminal:
$ make serve-app

常见问题

Duct 真的免费吗？

是的。Duct 采用 MIT 许可证，使用你自己的模型密钥免费。你直接向模型提供商付费，或者使用现有的 ChatGPT 方案登录。

我可以在没有账户的情况下运行 Duct 吗？

是的。克隆仓库，运行 make setup，添加一个模型密钥并启动后端和应用。无需涉及 Duct 账号。

选择自托管会失去什么？

Google Ads、GA4 和 Search Console 需要先使用你自己的 Google OAuth 客户端才能连接，且数据库、备份和升级均由你自己运行。

我可以使用 Duct 进行商业用途或分叉它吗？

是的。MIT 许可证允许商业使用、修改和重新分发。例外情况是 docs/guides 下的第三方文档以及 Duct 的名称和标识。

我如何贡献？

从 CONTRIBUTING.md 开始。路线图是公开看板，如果说明了智能体提供帮助的位置，我们欢迎通过智能体编写的 pull request。

在连接任何工具前请先阅读。
