知识

Duct 已知晓的关于 Tag Manager 的信息

  1. 01

    未发布前，任何内容都不会生效。

    工作区中的编辑不会更改你的网站。Duct 在那里暂存其更改，并且发布（它会替换所有访问者的实时容器）始终等待你的操作。

  2. 02

    回滚目标优先读取。

    发布前，Duct 会记录当前生效的版本，因此回滚会重新发布原有的内容。

  3. 03

    触发的代码仍可能已损坏。

    代码可以在每个页面触发，但可能未发送任何有用数据。Duct 检查 GA4 或 Mixpanel 中收到的数据，而不是触发状态。

  4. 04

    重命名不遵循引用。

    通过 API 重命名变量会使所有代码仍指向旧名称。Duct 会在同一变更中修补代码，或者不重命名。

设置

连接 Tag Manager 分三步

  1. 1

    在 Duct 中，打开工具箱并选择 Google Tag Manager。

  2. 2

    使用 Google 登录并允许访问以编辑和发布容器。

  3. 3

    选择此项目使用的容器。

Duct 在你登录时请求编辑和发布权限，因为修复代码需要这两项权限。编辑保留在工作区中，发布始终等待你的应用。

密钥和令牌由 Duct 的托管 API 加密存储，绝不会存储在你的浏览器中，你可以随时移除连接。自托管版本会将它们保存在你自己的机器上。

常见问题

Tag Manager，已回答

Duct 可以在 Tag Manager 中更改什么？

四种：创建/更新 GTM 代码（工作区）、创建/更新 GTM 变量（工作区）、发布 GTM 容器版本和重新发布旧的 GTM 版本。默认情况下，每项都等待你的应用，并且每项都可以回滚。

Duct 会自行发布到我的实时网站吗？

不。发布会替换所有访问者的实时容器，因此无论项目的自主性如何，它始终等待你的操作。工作区编辑可以在辅助模式下自行应用，并且在发布之前不会更改任何实时内容。

回滚如何运作？

发布前，Duct 会记录当前生效的版本。回滚会重新发布该版本，并且活动日志会显示两者。

免费吗？

是的。Duct 可免费使用你自己的模型密钥或你已有的 ChatGPT 套餐，核心部分采用 MIT 许可。付费套餐稍后会捆绑模型；目前开源的部分不会转为付费。哪些会收费。
