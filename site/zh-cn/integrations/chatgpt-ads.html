知识

Duct 已经了解的 关于 ChatGPT Ads 的信息

  1. 01

    Ads API 无法查看转化。

    其指标包括展示次数、点击次数、花费、CTR、CPC 和 CPM。像素转化仅在 Ads Manager 中显示，因此 Duct 从不单独以 CPC 来判断渠道的好坏。它会检查 Stripe。

  2. 02

    一个供应商的两个单元。

    洞察报告花费为小数 (18.42)；像素报告美分 (1499)。混合它们会导致 100 倍的错误，因此 Duct 在比较之前会进行转换。

  3. 03

    一个密钥，一个广告账户。

    广告 API 密钥精确地对应一个广告账户。Duct 会首先读取是哪个账户，因此来自错误账户的密钥会显示错误信息而不是看起来为空。

  4. 04

    只有账单支付方知道。

    每个广告平台都会报告其归因的转化。Duct 将它们与 Stripe 进行核对，而不是相互核对。

设置

分三步连接 ChatGPT Ads

  1. 1

    在 OpenAI Ads Manager 中，为你想要读取的广告账户创建一个广告 API 密钥。

  2. 2

    在 Duct 中，打开工具箱，选择 OpenAI Ads 并粘贴密钥。

  3. 3

    Duct 显示密钥所属的广告账户，然后读取其广告系列和每日总计。

广告 API 密钥仅限于一个广告账户，并且 OpenAI 在 API 测试版期间按账户授予 API 访问权限。Duct 仅使用密钥进行读取；它没有 ChatGPT Ads 的更改操作。

密钥和令牌由 Duct 的托管 API 加密存储，绝不会存储在你的浏览器中，你可以随时移除连接。自托管版本会将它们保存在你自己的机器上。

常见问题

ChatGPT Ads，已解答

Duct 能看到 ChatGPT Ads 的转化吗？

不，因为 OpenAI Ads API 不报告这些数据；像素转化仅在 Ads Manager 中显示。Duct 根据 Stripe 结算的金额和 GA4 看到的数据来衡量渠道，这才是决定预算的数字。

Duct 会更改我的 ChatGPT Ads 广告系列吗？

不。该连接器是只读的。Duct 可以建议在广告系列或渠道之间调整预算；你需要在 Ads Manager 中进行更改。

ChatGPT Ads 和 OpenAI Ads 是同一个东西吗？

是的。OpenAI 通过其 Ads Manager 和 Ads API 销售在 ChatGPT 中运行的广告。Duct 应用将该连接器列为 OpenAI Ads。

免费吗？

是的。Duct 可免费使用你自己的模型密钥或你已有的 ChatGPT 套餐，核心部分采用 MIT 许可。付费套餐稍后会捆绑模型；目前开源的部分不会转为付费。哪些会收费。
