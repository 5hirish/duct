Search Console，深入到转化查询。

它可以更改什么

无。

Duct 没有 Search Console 的更改操作，因此无法在 Search Console 中编辑任何内容。但它仍然可以为你推荐在那里进行的更改。

知识

Duct 已知 关于 Search Console 的信息

  1. 01

    长尾是工作的重点。

    Search Console 按点击量排序，每次返回 25,000 行。如果读取不足，零点击展示量以及接下来要写的内容列表就会消失。Duct 读取两页，最多 50,000 行。

  2. 02

    大多数点击没有查询词。

    Google 隐藏了罕见查询，因此页面表格显示的点击量是查询表格的数倍。Duct 使用页面来衡量数量，使用查询来衡量具体词条。

  3. 03

    最近三天的数据不是最终数据。

    最终数据将最新几天的数据归零，这看起来像一个断崖。Duct 请求所有数据，这样一周的结束才是真正的结束。

  4. 04

    查询与页面是唯一能看到关键词蚕食的视图。

    你的两个页面争夺同一个查询的情况在其他地方无法显示。Duct 同时读取查询和页面。

常见问题

Search Console，已解答

Duct 可以在 Search Console 中进行任何更改吗？

不。它只请求读取权限，并且没有 Search Console 的更改操作。它读取查询、页面和排名，并能告诉你网站上需要更改什么。

为什么 Duct 的自然流量数据与 GA4 的不同？

Search Console 统计来自 Google 的点击量；GA4 统计来自所有搜索引擎的会话量。GA4 的数据是 Search Console 的 1 到 3.5 倍是正常的。如果超出这个范围，Duct 会怀疑是机器人或标签中断，然后才会报告任何数字。

它读取了我的多少资源？

每个窗口最多 50,000 行，Search Console 的两页数据。超过这个数量，行数据太少，无法改变答案。

免费吗？
