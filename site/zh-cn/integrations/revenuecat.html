它可以更改什么

无。

Duct 没有 RevenueCat 变更操作，因此无法在 RevenueCat 中编辑任何内容。它仍然可以推荐你进行更改。

知识

Duct 已知的信息 关于 RevenueCat

  1. 01

    RevenueCat 是应用收入的真相。

    安装和应用内事件是信号。RevenueCat 会看到退款、账单重试和取消，因此 Duct 会对照它检查应用广告转化，从不反向操作。

  2. 02

    SDK 密钥无法读取 API。

    以 appl_ 或 goog_ 开头的密钥用于应用。读取需要秘密 V2 密钥，如果你粘贴了错误的类型，Duct 会告诉你。

  3. 03

    客户 ID 已哈希。

    Duct 保留每个应用用户 ID 的 SHA-256：足以将一次拉取连接到下一次，但无法用于识别个人。

  4. 04

    指标受到严格的速率限制。

    RevenueCat 的指标 API 每分钟允许 25 次请求。Duct 会控制读取速度，而不是通过失败来触及限制。

设置

连接 RevenueCat 分三步

  1. 1

    在 RevenueCat 中，打开项目设置，然后选择 API 密钥，并创建秘密 API 密钥 (V2)。

  2. 2

    授予它读取项目配置、客户信息和图表指标的权限。

  3. 3

    在 Duct 中，打开工具箱，选择 RevenueCat 并粘贴密钥。

只读：具有读取范围的密钥无法更改产品或订阅，Duct 没有 RevenueCat 更改操作。

密钥和令牌由 Duct 的托管 API 加密存储，绝不会存储在你的浏览器中，你可以随时移除连接。自托管版本会将它们保存在你自己的机器上。

常见问题

RevenueCat，已回答

Duct 可以更改产品、优惠或订阅吗？

不。Duct 没有 RevenueCat 更改操作。它读取指标、配置和客户样本。

Duct 会保留哪些客户数据？

来自 500 名客户的样本：每位客户首次和最后一次出现的时间、国家和平台，以及他们的活跃权益，用户 ID 已哈希处理。

为什么是秘密密钥而不是我应用中的密钥？

你应用中的密钥是公共 SDK 密钥，它们无法读取 RevenueCat 的 REST API。具有读取范围的秘密 V2 密钥可以。

免费吗？

是的。Duct 可免费使用你自己的模型密钥或你已有的 ChatGPT 套餐，核心部分采用 MIT 许可。付费套餐稍后会捆绑模型；目前开源的部分不会转为付费。哪些会收费。
