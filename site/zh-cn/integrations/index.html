Duct 连接到哪些工具？

Google Ads、Meta Ads、Apple Search Ads、ChatGPT Ads、Google Analytics 4、Google Search Console、Google Tag Manager、Mixpanel、Microsoft Clarity、GrowthBook、GitHub、Stripe 和 RevenueCat。当你使用 Google 登录时，这四种 Google 工具会连接；其余的只需粘贴一次密钥即可。HubSpot 即将推出。

Duct 需要我的账户的写入权限吗？

不。答案和简报在任何地方都只需读取权限。四个连接器也可以进行更改（Google Ads、GA4、Tag Manager 和 Mixpanel），总共有 20 种，默认情况下，每种更改都等待你的应用。

我的连接器凭据存储在哪里？

密钥和令牌由 Duct 的托管 API 加密存储，绝不会存储在你的浏览器中，你可以随时移除连接。自托管版本会将它们保存在你自己的机器上。

我可以请求一个连接器吗？

是的。在 GitHub 上发起讨论，说明工具名称和你希望它回答的问题。当某个问题需要连接器时，我们就会构建它。

Duct 有 MCP 服务器吗？

还没有。一个 MCP 服务器，以便 Claude、Cursor 和其他智能体可以使用 Duct 的连接器，已计划在问题 #197 中实现。
