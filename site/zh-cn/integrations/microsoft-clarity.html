它可以更改什么

无。

Duct 没有 Clarity 修改操作，因此无法编辑 Clarity 中的任何内容。它仍然可以为你推荐在那里进行的更改。

知识

Duct 已经了解的关于 Clarity的信息

  1. 01

    Clarity 保留三天数据。

    它的 API 只返回最近一到三天的数据，所以它是一个健康检查，而不是历史记录。Duct 会读取它以了解当前发生的情况，并在需要关注时每天读取。

  2. 02

    每天十次调用，很困难。

    Clarity 允许每个项目每天十次 API 请求，Duct 读取一次需要两次，因此 Duct 从不轮询。达到限制意味着要等到明天，而不是重试。

  3. 03

    机器人包含在会话中。

    Clarity 会将机器人会话与其他会话一起计数。Duct 在计算任何比率之前会将其剔除。

  4. 04

    按份额比较，而不是按数量比较。

    摩擦数据是指至少发生过一次摩擦的会话所占的比例。Duct 会根据这个比例来比较页面，这样繁忙的页面就不会因为繁忙而显得更差。

设置

连接 Clarity 分三步

  1. 1

    在 Clarity 中，打开“设置”，然后选择“数据导出”，生成一个 API 令牌。

  2. 2

    在 Duct 应该读取的项目中创建它：令牌就是项目，旁边没有 ID。

  3. 3

    在 Duct 中，打开工具箱，选择 Microsoft Clarity 并粘贴令牌。

只读：导出令牌只能读取，Duct 没有 Clarity 修改操作。

密钥和令牌由 Duct 的托管 API 加密存储，绝不会存储在你的浏览器中，你可以随时移除连接。自托管版本会将它们保存在你自己的机器上。

常见问题

Clarity，已回答

Duct 能查看会话录像吗？

不。它读取的是 Clarity 导出的每页数据，而不是录像或热力图。

为什么只有最近三天的数据？

这是 Clarity 的 API 返回的所有内容。Duct 将其视为实时健康信号，当需要跟踪问题时，会每日读取。

Duct 能修改 Clarity 中的任何内容吗？

不。它没有 Clarity 修改操作。它可以告诉你哪个页面需要修复。

免费吗？

是的。Duct 可免费使用你自己的模型密钥或你已有的 ChatGPT 套餐，核心部分采用 MIT 许可。付费套餐稍后会捆绑模型；目前开源的部分不会转为付费。哪些会收费。
