它可以更改什么

无。

Duct 没有 Stripe 变更操作，因此无法编辑 Stripe 中的任何内容。它仍然可以为你推荐一个变更，供你自行操作。

知识

Duct 已知 关于 Stripe 的信息

  1. 01

    Stripe 是资金真相。

    广告平台报告它们归因给自己的转化；Stripe 报告已结算的收入。当两者不一致时，Duct 以 Stripe 为准。

  2. 02

    未完成付款的结账不算作销售。

    未完成的订阅是废弃或失败的结账。统计它们会将获客量夸大两到三倍，因此 Duct 会将其排除在外。

  3. 03

    大多数交易都是续订。

    交易量主要来自现有客户的再次付款。Duct 在衡量获客时，统计的是新的付费订阅，而不是交易。

  4. 04

    退款已扣除，并且没有计划显示为零。

    收入是扣除退款后的净额，价格来自订阅项目，因此多项目计划永远不会显示为 $0。

设置

连接 Stripe 分三步

  1. 1

    在 Stripe 中，打开 Developers，然后是 API keys，并创建一个受限密钥。

  2. 2

    授予它对 Subscriptions、Charges、Invoices、Customers、Products 和 Prices 的只读访问权限。仅此而已。

  3. 3

    在 Duct 中，打开工具箱，选择 Stripe 并粘贴密钥。Duct 会检查每个权限，并指出任何缺失的权限。

设计上只读：具有只读权限的受限密钥无法转移资金或编辑客户，并且 Duct 根本没有 Stripe 变更操作。

密钥和令牌由 Duct 的托管 API 加密存储，绝不会存储在你的浏览器中，你可以随时移除连接。自托管版本会将它们保存在你自己的机器上。

常见问题

Stripe，已回答

Duct 可以在 Stripe 中转移资金或编辑客户信息吗？

不。它通过只读权限的受限密钥连接，并且 Duct 没有 Stripe 变更操作。它只读取订阅和交易并报告相关信息。

Duct 需要哪些 Stripe 权限？

对 Subscriptions、Charges、Invoices、Customers、Products 和 Prices 的只读访问权限。如果缺少其中一项，Duct 会在你连接时指出，而不是将数据中的缺失报告为零。

为什么 Stripe 与我的广告平台报告不符？

因为每个平台都根据自己的归因窗口统计其归因的购买，而且其中几个平台会声称是同一笔销售。预计平台总数将是 Stripe 结算金额的 1.5 到 3 倍。Duct 会根据 Stripe 核对平台数据，而不是反过来。

免费吗？

是的。Duct 可免费使用你自己的模型密钥或你已有的 ChatGPT 套餐，核心部分采用 MIT 许可。付费套餐稍后会捆绑模型；目前开源的部分不会转为付费。哪些会收费。
