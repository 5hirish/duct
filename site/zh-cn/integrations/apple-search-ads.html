知识

Duct 关于 Apple Search Ads 已知的信息

  1. 01

    Apple 只统计安装量，不统计收入。

    Apple Search Ads 中没有收入或订阅者指标。Duct 根据 RevenueCat 或 Stripe 来评估广告系列，而不是根据其安装量。

  2. 02

    报告涵盖整个组织。

    Apple 的广告系列报告混合了组织中的所有应用。Duct 首先将它们筛选到你的广告系列，这样其他应用的支出就不会计入你的总额。

  3. 03

    安装量已重命名。

    API 版本 5 将安装量分为点击转化和总安装量（包括展示转化）。旧字段读取为零，因此 Duct 读取两个新字段。

  4. 04

    资金以文本形式到达。

    Apple 返回的每个金额都是带货币符号的字符串。Duct 在进行任何加总之前会解析每个金额。

设置

三步连接 Apple Search Ads

  1. 1

    生成 EC P-256 密钥对，并在 Apple Search Ads 的“账户设置”下的“API”中上传公钥。

  2. 2

    记下 Apple 为其显示的客户端 ID、团队 ID 和密钥 ID。

  3. 3

    在 Duct 中，打开工具箱，选择 Apple Search Ads 并粘贴三个 ID 和私钥。

只读：Duct 没有 Apple Search Ads 更改操作，并且为 API 用户提供只读角色，因此密钥也无法更改广告系列。

密钥和令牌由 Duct 的托管 API 加密存储，绝不会存储在你的浏览器中，你可以随时移除连接。自托管版本会将它们保存在你自己的机器上。

常见问题

Apple Search Ads，已回答

Duct 能否更改 Apple Search Ads 中的出价或预算？

不会。Duct 没有 Apple Search Ads 更改操作。它读取广告系列及其报告，并可以为你推荐在 Apple 控制台中进行的更改。

Duct 为何需要 RevenueCat 或 Stripe 来连接 Apple？

因为 Apple 只统计安装量。这些安装是否启动了试用或进行了付费，这在你的账单中，因此 Duct 会结合 Apple 的数据读取它，然后判断一个广告系列的好坏。

我们的 Apple Ads 组织运行多个应用。数据会混淆吗？

不会。Duct 根据它为你列出的广告系列来调整每份报告，因此其他应用的支出永远不会计入这些总额。

免费吗？

是的。Duct 可免费使用你自己的模型密钥或你已有的 ChatGPT 套餐，核心部分采用 MIT 许可。付费套餐稍后会捆绑模型；目前开源的部分不会转为付费。哪些会收费。
