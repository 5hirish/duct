你的智能体将获得什么

它本身就很擅长写作。现在它更懂你的数据。

通用助手可以推理任何事情。但它无法查看你的收入、记住上个月的情况或保存简报。Duct 为它赋予这三项能力。

Duct 核对的数据

Duct 会在代码中汇总每次拉取的数据，并将总额与转化率提供给你的智能体，因此简报中引用的金额是 $18,420，而不是模型自己在数千行数据上算出的结果。

有何与众不同之处

连接器向你的智能体提供数据行。Duct 则向它提供答案。

很多服务器都会将你的数据传递给智能体。然后智能体必须求和、猜测上下文，并每次都从空白提示词开始。

原始数据连接器提供给它Duct 提供给它
需要自行相加的数据行Duct 在代码中已核对的总量和比率，及其所覆盖的时间范围
上次的记录没有任何保留根据问题排序的你所决定、发布和衡量的记录
每次都是空白提示词Duct 自有的操作指南，附有各工具如何报告错误数字的说明
在工具允许的任何地方直接进行更改保留在 Duct 中等待你批准的提案
在聊天中随着滚动而消失的回答在 Duct 中保存、具备版本控制且易于共享的简报

专为交付给智能体而构建

它负责干活。密钥由你掌控。

智能体会受其读取内容的影响。因此无论你开放什么权限，重要事项绝不由它擅自执行。

在 Duct 中始终归你所有
  • 批准或应用变更、发布帖子、连接工具。无论你开放什么权限，任何智能体都无法擅自操作。
  • 你的密码和密钥。没有任何智能体能看到它们。
  • 在“活动”中以其自身名称记录它保存的所有内容。修改只需一键即可撤销。
  • 来自网页、搜索词或帖子的文本在送达时会被标记为数据，绝不会被当作指令。
  • 关闭开关。在“设置”中断开连接，它将在下一次调用时停止。

通过智能体设置

8 个智能体。一个地址。

每个智能体都连接到同一个服务器。选择你的智能体以获取具体步骤。

Claude Code

  1. 在你的终端中，运行： 
    claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp
  2. 在 Claude Code 中，运行 /mcp，选择 duct 并选择 Authenticate。
  3. 你的浏览器将打开 Duct。选择它可执行的操作，然后点击“允许”。
  4. 运行 /mcp__duct__insights_brief，或索取本周简报。

Codex

  1. 在你的终端中，运行： 
    codex mcp add duct --url https://mcp.getduct.ai/mcp
  2. 然后登录： 
    codex mcp login duct
  3. 你的浏览器将打开 Duct。选择它可执行的操作，然后点击“允许”。

Cursor

  1. 将 Duct 添加到 ~/.cursor/mcp.json： 
    {
  "mcpServers": {
    "duct": {
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. 在 Cursor 的 MCP 设置中，点击 duct 服务器上的登录提示。
  3. 你的浏览器将打开 Duct。选择它可执行的操作，然后点击“允许”。

Gemini CLI

  1. 将 Duct 添加至 ~/.gemini/settings.json： 
    {
  "mcpServers": {
    "duct": {
      "httpUrl": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. 启动 Gemini CLI 并登录： 
    /mcp auth duct
  3. 你的浏览器将打开 Duct。选择它可执行的操作，然后点击“允许”。
  4. 运行 /insights_brief，或获取本周的简报。

VS Code

  1. 打开命令面板并运行 MCP: Add Server。
  2. 选择 HTTP，粘贴地址并将其命名为 duct： 
    https://mcp.getduct.ai/mcp
  3. 首次使用 Duct 时，VS Code 会提示你登录。你的浏览器将打开 Duct。选择它能做什么，然后点击“允许”。

OpenCode

  1. 将 Duct 添加到 opencode.json： 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. 然后登录： 
    opencode mcp auth duct
  3. 你的浏览器将打开 Duct。选择它可执行的操作，然后点击“允许”。

Claude，在 claude.ai 或 Claude Desktop 上

  1. 在 claude.ai 或 Claude Desktop 中，打开“设置”→“连接器”，然后选择“添加自定义连接器”。
  2. 命名为 Duct 并粘贴地址： 
    https://mcp.getduct.ai/mcp
  3. 点击“连接”。Duct 会在你的浏览器中打开。选择它能做什么，然后点击“允许”。

ChatGPT

  1. 在 ChatGPT 的设置中，开启开发者模式。
  2. 使用此地址添加连接器，并选择 OAuth 进行身份验证： 
    https://mcp.getduct.ai/mcp
  3. Duct 会在你的浏览器中打开。选择允许其执行的操作，然后点击“允许”。

访问

所有智能体都已列出。断开任何一个。

你看到所有已连接的智能体

在 Duct 中，打开设置 → 连接你的 AI 智能体。你允许的每个智能体都会显示在那里，包含其权限与适用项目，你随时可以断开连接。断开连接的智能体将在下一次调用时停止操作。

没有浏览器？使用令牌。

适用于 CI、远程机器或无需登录的智能体。在同一设置页面的“没有浏览器？使用令牌”下方创建一个，选项相同。你的智能体将其作为请求头发送：

Authorization: Bearer duct_mcp_…

在 Claude Code 中：

claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

问题

人们常问的问题。以及解决方案。

在连接之前

我需要 API 密钥吗？

不需要。你的智能体在你已订阅的套餐上运行，Duct 不会为此调用任何模型。保存的密钥仅用于生成图片以及 Duct 在你离线时运行的任务（例如定时简报）。

它能读取我的哪些工具？

你在 Duct 中连接的 Stripe、Meta Ads、Mixpanel、GitHub、RevenueCat、Clarity、GrowthBook、Apple Search Ads、RSS 订阅源及其他工具。在确认 Google 对外部 AI 助手的政策前，Google Analytics、Search Console、Google Ads 和 Tag Manager 暂时留在 Duct 自有的智能体内部。

它能变更我的广告账户吗？

只有在开启建议变更时，且仅作为提议。它会在 Duct 的审核队列中等待，直到你在那里批准它。没有任何智能体可以批准或应用变更。

Duct 会看到我的对话吗？

不会。Duct 只能看到你的智能体对其发起的调用（例如请求的数据及原因），绝不会看到聊天中的其他内容。

笔记本电脑合上时，简报还会运行吗？

不是来自你的智能体。定时简报由 Duct 使用保存的密钥运行，因为没有人会让自己的智能体在凌晨 3 点运行。你的智能体撰写的内容会归档到同一个库中。

什么是 insights_brief？

Duct 的简报剧本以斜杠命令形式提供：在 Claude Code 中为 /mcp__duct__insights_brief，在 Gemini CLI 中为 /insights_brief。在任何其他智能体中，只需索取本周简报，它就会调用相同的剧本。

如果出现问题

我的浏览器从未打开

亲自发起登录：在 Claude Code 中运行 /mcp，在 Codex 中运行 codex mcp login duct，在 Gemini CLI 中运行 /mcp auth duct，或在 OpenCode 中运行 opencode mcp auth duct。

它显示无法注册，或“不支持动态客户端注册”

将你的智能体更新到最新版本然后重试。如果仍然失败，请改用令牌连接。

它已工作，但现在收到 401 错误

你已在 Duct 中断开它的连接，或它在 90 天未使用后登录失效。请从你的智能体再次登录。

我预期的工具不在其中

你的智能体只能看到它登录时你允许的内容。请在 Duct 中断开连接，重新连接，并选择“与我协作”。

我让它设置项目，但没有任何改变

草稿绝不会覆盖你在 Duct 中输入的内容。它只填充空白字段或替换之前的草稿。请检查 Duct 中的项目页面。

我自行托管 Duct

使用你自己的 API 地址，后接 /mcp，以代替 https://mcp.getduct.ai/mcp。
