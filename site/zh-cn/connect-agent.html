Duct 的 MCP 服务器 · 浏览器登录

通过你的智能体使用 Duct。
无需复制令牌。

将此地址添加到 Claude Code、Codex、Cursor、VS Code、OpenCode、Claude 或 ChatGPT。你的浏览器将打开 Duct，你点击“允许”，然后你的智能体即可读取你的项目并起草其详细信息。

服务器地址 
https://api.getduct.ai/mcp

希望 Duct 自己的智能体调用你的 MCP 服务器吗？那是另一个方向：你在 Duct 中的 MCP 服务器 →

如何连接你的智能体

添加它，允许它，询问它。

01

将 Duct 添加到你的智能体

将上述地址提供给你的智能体，通过一个命令或一行设置。每个智能体的具体步骤如下。

$ claude mcp add \
    --transport http \
    --scope user duct \
    https://api.getduct.ai/mcp
02

登录并点击允许

你的浏览器将在 Duct 上打开，并询问你的智能体是否可以使用你的账户。点击允许。没有可复制的令牌。

duct

Claude Code 想使用你的 Duct 账户

取消允许
03

问它一些问题

尝试“在 Duct 中设置此产品”。你的智能体读取你的仓库并起草项目的描述、受众和竞争对手。

在 Duct 中设置此产品。

已从仓库起草描述、受众和竞争对手。它们已在 Duct 中的项目里。

通过智能体设置

七个智能体。一个地址。

每个智能体都连接到同一个服务器。选择你的智能体以获取具体步骤。

Claude Code

  1. 在你的终端中，运行： 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. 在 Claude Code 中，运行 /mcp，选择 duct 并选择 Authenticate。
  3. 你的浏览器将在 Duct 上打开。点击允许。

Codex

  1. 在你的终端中，运行： 
    codex mcp add duct --url https://api.getduct.ai/mcp
  2. 然后登录： 
    codex mcp login duct
  3. 你的浏览器将在 Duct 上打开。点击允许。

Cursor

  1. 将 Duct 添加到 ~/.cursor/mcp.json： 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. 在 Cursor 的 MCP 设置中，点击 duct 服务器上的登录提示。
  3. 你的浏览器将在 Duct 上打开。点击允许。

VS Code

  1. 打开命令面板并运行 MCP: Add Server。
  2. 选择 HTTP，粘贴地址并将其命名为 duct： 
    https://api.getduct.ai/mcp
  3. VS Code 首次使用 Duct 时会要求你登录。你的浏览器会在 Duct 上打开。点击允许。

OpenCode

  1. 将 Duct 添加到 opencode.json： 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. 然后登录： 
    opencode mcp auth duct
  3. 你的浏览器将在 Duct 上打开。点击允许。

Claude，在 claude.ai 或 Claude Desktop 上

  1. 在 claude.ai 或 Claude Desktop 中，打开“设置”→“连接器”，然后选择“添加自定义连接器”。
  2. 命名为 Duct 并粘贴地址： 
    https://api.getduct.ai/mcp
  3. 点击连接。Duct 在你的浏览器中打开。点击允许。

ChatGPT

  1. 在 ChatGPT 的设置中，开启开发者模式。
  2. 使用此地址添加连接器，并选择 OAuth 进行身份验证： 
    https://api.getduct.ai/mcp
  3. Duct 在你的浏览器中打开。点击“允许”。

另一个智能体？如果它可以通过地址添加远程 MCP 服务器，请给它相同的地址。如果它无法登录，请使用令牌。

你的智能体能做什么

它读取并起草。你来决定。

Duct 今天为你的智能体提供了三个工具。批准、应用和连接仍由你掌控，在 Duct 中。

你的智能体可以
  • 列出你的项目。
  • 读取一个项目。
  • 从你的仓库或文件中起草项目的描述、受众和竞争对手。
它绝不能
  • 批准或应用变更。
  • 连接工具。
  • 查看密钥或凭据。
  • 覆盖你在 Duct 中输入的内容。草稿只填充空白或替换之前的草稿。

每个变更都显示在项目的活动中。

访问

所有智能体都已列出。断开任何一个。

你看到所有已连接的智能体

在 Duct 中，打开“设置”→“连接你的 AI 智能体”。你允许的每个智能体都在那里，你可以断开它的连接。已断开连接的智能体在下次调用时停止。

没有浏览器？使用令牌。

适用于 CI、远程机器或无需登录的智能体。在同一设置页面中，在“没有浏览器？使用令牌”下创建一个。你的智能体将其作为标头发送：

Authorization: Bearer duct_mcp_…

在 Claude Code 中：

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

故障排除

卡住了？从这里开始。

我的浏览器从未打开

自行开始登录：在 Claude Code 中运行 /mcp，在 Codex 中运行 codex mcp login duct，或在 OpenCode 中运行 opencode mcp auth duct。

它显示无法注册，或“不支持动态客户端注册”

将你的智能体更新到最新版本然后重试。如果仍然失败，请改用令牌连接。

它已工作，但现在收到 401 错误

你已在 Duct 中断开它的连接，或它在 90 天未使用后登录失效。请从你的智能体再次登录。

我让它设置项目，但没有任何改变

草稿绝不会覆盖你在 Duct 中输入的内容。它只填充空白字段或替换之前的草稿。请检查 Duct 中的项目页面。

我自行托管 Duct

使用你自己的 API 地址后跟 /mcp，代替 https://api.getduct.ai/mcp。
