从你的智能体中使用 Duct。无需复制令牌。

将一个地址粘贴到你的智能体中，点击一次“允许”，它即可读取并起草你的 Duct 项目。

https://api.getduct.ai/mcp

设置指南：

  • Claude Code
  • Codex
  • Cursor
  • VS Code
  • OpenCode
  • Claude
  • ChatGPT

选择你的智能体。粘贴一行内容。

Claude Code

  1. 在你的终端中运行此命令： 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. 在 Claude Code 中运行 /mcp，选择 duct，选择 Authenticate 并点击允许。

Codex

  1. 在你的终端中运行以下命令： 
    codex mcp add duct --url https://api.getduct.ai/mcp
    codex mcp login duct
  2. 你的浏览器将在 Duct 上打开。点击允许。

Cursor

  1. 将此内容添加到 ~/.cursor/mcp.json： 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. 在 Cursor 的 MCP 设置中，登录 duct 并点击允许。

VS Code

  1. 从命令面板运行 MCP: Add Server，选择 HTTP 并粘贴： 
    https://api.getduct.ai/mcp
  2. 将其命名为 duct。它首次使用 Duct 时，请在浏览器中点击“允许”。

OpenCode

  1. 在你的终端中运行以下命令： 
    opencode mcp add duct --global --url https://api.getduct.ai/mcp
    opencode mcp auth duct
  2. 你的浏览器将在 Duct 上打开。点击允许。

Claude，在 claude.ai 或 Claude Desktop 上

  1. 在“设置 → 连接器”中，选择“添加自定义连接器”，将其命名为 Duct 并粘贴： 
    https://api.getduct.ai/mcp
  2. 点击“连接”，然后点击“允许”。

ChatGPT

  1. 在 ChatGPT 的设置中，开启开发者模式。
  2. 使用 OAuth 和此地址添加连接器： 
    https://api.getduct.ai/mcp
  3. 你的浏览器将在 Duct 上打开。点击允许。

没有浏览器？使用令牌。

适用于 CI 或远程机器。在同一设置页面上创建一个；你的智能体会将其作为请求头发送。

Authorization: Bearer duct_mcp_…

在 Claude Code 中：

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

遇到问题？从这里开始。

我的浏览器从未打开

自行开始登录：在 Claude Code 中运行 /mcp，在 Codex 中运行 codex mcp login duct，或在 OpenCode 中运行 opencode mcp auth duct。

它显示无法注册，或“不支持动态客户端注册”

将你的智能体更新到最新版本然后重试。如果仍然失败，请改用令牌连接。

它已工作，但现在收到 401 错误

你已在 Duct 中断开它的连接，或它在 90 天未使用后登录失效。请从你的智能体再次登录。

我让它设置项目，但没有任何改变

草稿绝不会覆盖你在 Duct 中输入的文本。它只会填写空白字段或替换先前的草稿。若要更改你设置的字段，请明确说明修改该字段。

我自行托管 Duct
