由你选择

设置项目，或与你协同工作。

当你的智能体登录时，由你选择其权限及可访问的项目。随时可以在设置中更改。

  • 协助设置我的项目。它会根据你的代码库起草项目的描述、受众和竞争对手。
  • 与我协同。它还会读取你的工具，记住重要事项并撰写简报。提议的变更、帖子草稿以及基于你自身密钥的图像生成功能默认关闭，直到你手动开启。
  • 你的所有项目，或仅你选择的项目。

未经你的许可，智能体绝不能：批准或应用变更、发布内容、连接工具、获取你的密码和密钥。它保存的所有内容都会以其名称显示在“活动”中，只需一键即可撤销编辑。

由智能体设置

8 个智能体。一个地址。

每个智能体都连接到同一个地址。选择你的智能体。

Claude Code

  1. 在终端中运行： 
    claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp
  2. 在 Claude Code 中，运行 /mcp，选择 duct 并选择 Authenticate。
  3. 在浏览器中，选择它可以执行的操作，然后点击 Allow。
  4. 运行 /mcp__duct__insights_brief 获取 Duct 的简报剧本，或直接提问。

Codex

  1. 在终端中运行： 
    codex mcp add duct --url https://mcp.getduct.ai/mcp
  2. 然后登录： 
    codex mcp login duct
  3. 在浏览器中，选择它可以执行的操作，然后点击 Allow。

Cursor

  1. 将 Duct 添加至 ~/.cursor/mcp.json： 
    {
  "mcpServers": {
    "duct": {
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. 在 Cursor 的 MCP 设置中，点击 duct 上的 Login。
  3. 在浏览器中，选择它可以执行的操作，然后点击 Allow。

Gemini CLI

  1. 将 Duct 添加至 ~/.gemini/settings.json： 
    {
  "mcpServers": {
    "duct": {
      "httpUrl": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. 启动 Gemini CLI 并登录： 
    /mcp auth duct
  3. 在浏览器中，选择它可以执行的操作，然后点击 Allow。
  4. 运行 /insights_brief 获取 Duct 的简报剧本，或直接提问。

VS Code

  1. 打开命令面板并运行 MCP: Add Server。
  2. 选择 HTTP，粘贴地址并将其命名为 duct： 
    https://mcp.getduct.ai/mcp
  3. VS Code 首次使用时会要求你登录。在浏览器中选择其权限，然后点击允许。

OpenCode

  1. 将 Duct 添加至 opencode.json： 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. 然后登录： 
    opencode mcp auth duct
  3. 在浏览器中，选择它可以执行的操作，然后点击 Allow。

Claude，在 claude.ai 或 Claude Desktop 上

  1. 打开“设置 → 连接器”，然后选择“添加自定义连接器”。
  2. 将其命名为 Duct 并粘贴地址： 
    https://mcp.getduct.ai/mcp
  3. 点击 Connect。在浏览器中，选择它可以执行的操作，然后点击 Allow。

ChatGPT

  1. 在 ChatGPT 的设置中，开启开发者模式。
  2. 使用此地址和 OAuth 登录添加连接器： 
    https://mcp.getduct.ai/mcp
  3. 在浏览器中，选择它可以执行的操作，然后点击 Allow。

要接入其他智能体？提供相同的地址，如果无法登录，可以使用令牌。

没有浏览器？使用令牌。

适用于 CI 或远程机器。在“设置”→“连接你的 AI 智能体”中创建一个，包含相同的选项。该页面还会列出你允许的所有智能体，并可断开其中任何一个。将其作为请求头发送：

Authorization: Bearer duct_mcp_…

在 Claude Code 中：

claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

常见问题

常见问题。以及解决方法。

连接之前

我需要 API 密钥吗？

否。它直接使用你现有的套餐运行。保存的密钥仅用于生成图片和定时简报。

它可以读取我的哪些工具？

Stripe、Meta Ads、Mixpanel、GitHub、RevenueCat 以及其他连接均在 Duct 中完成。Google Analytics、Search Console、Ads 和 Tag Manager 暂时保留在 Duct 自身的智能体中，等待 Google 对外部助手的政策确定。

它能修改我的广告账号吗？

仅以建议形式呈现（需开启此功能）。建议会在 Duct 中保留，直到你批准。没有智能体可以应用变更。

Duct 能看到我的对话吗？

否。Duct 只能看到你的智能体对它的调用，无法查看对话中的其他内容。

笔记本电脑合上时，简报还会运行吗？

并非来自你的智能体。定时简报会在 Duct 中基于保存的密钥运行，因为没有人的智能体会在凌晨 3 点运行。

如果出现问题

我的浏览器从未打开

手动启动：Claude Code 中的 /mcp、codex mcp login duct、Gemini CLI 中的 /mcp auth duct，或 opencode mcp auth duct。

它显示无法注册，或“不支持动态客户端注册”

更新你的智能体并重试。如果仍然失败，请使用令牌。

它已工作，但现在收到 401 错误

连接已断开，或已有 90 天未被使用。请从你的智能体重新登录。

没有找到我需要的工具

它只能看到你允许的内容。在 Duct 中断开连接，重新连接并选择 Work alongside me。

我自行托管 Duct

使用你自己的 API 地址，后接 /mcp。
