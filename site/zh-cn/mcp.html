常见问题与错误含义

它显示“Duct 只连接到公共互联网上的服务器”

该地址指向你自己的计算机或私有网络。Duct 从云端调用服务器，因此只能访问公开的 https 地址。在本地通过 stdio 运行的服务器同样无法使用。

它需要 API 密钥

该服务器未提供 Duct 可用的一键登录。请在供应商设置中创建密钥并粘贴到同一个对话框中。Duct 会加密保存密钥，且仅发送给该服务器。

它显示“需要重新连接”

登录已过期，或在供应商端被撤销。请在工具箱中按“重新连接”并再次登录。

模型能看到我的密钥吗？

不会。登录信息和密钥在 Duct 端保持加密，并随调用传输。服务器返回的内容仅作为数据读取，绝不会被解析为指令。

与我共享项目的人可以使用我的服务器吗？

不能。服务器归连接它的个人所有，仅用于其自身的对话。团队成员需要自行连接自己的服务器。

工具调用会产生费用吗？

部分会由供应商收取费用。OpenSEO 研究调用会消耗你的 OpenSEO 额度，与其他应用完全相同。

这与 Claude 或 ChatGPT 的连接器有何不同？

它们的目录列出的多为相同的供应商服务器。Duct 会直接连接这些服务器，无论你使用的是什么模型。
