智能体提议。你来批准。

Duct 可以为你的广告或分析工具准备变更。没有任何工具允许它自行批准变更，因此无法说服它这样做。

无论如何设置，任何破坏性操作都需要等待你点击确认。

一小部分可逆的变更可能会自动应用，且仅当你开启该功能时才会如此。

租用智能体框架，绝不绑定终生。

智能体框架每周都在变化。Duct 的提示词、工具和评分均为纯 Python 实现，如果框架导入出现在少数适配器文件之外，测试就会失败。

在第二次使用时进行抽象。

一次实现是猜测。两次实现才是事实。当第二个智能体需要共享适配器时，这些适配器才被提取出来，并由白名单指定使用哪一个。

API 密钥不等于权限。

应用的密钥会发送至浏览器，因此它只能证明是哪个应用在调用，而无法证明是谁在调用。每个项目路由都会检查你是否为成员，非成员将收到 404 错误。

测试会遍历每个路由，如果存在未要求用户登录的路由且旁边未注明原因，测试将失败。

你的密钥，你的模型选择。

使用来自 Anthropic、OpenAI、Google、xAI 或 OpenRouter 的密钥，或者运行本地模型。你挑选 3 个模型；Duct 决定具体任务使用哪一个。

桌面应用会将你的密钥保存在操作系统密钥链中。如果完全不想使用任何 Duct 服务器，自托管版本可以在你的机器上运行整个后端。

注释解释缘由。

重复下方代码含义的注释会教会人们跳过注释。值得写的注释应当指出潜在威胁、失败原因或被弃用的选项。

在智能体协助编写的代码中，这一依据是检查下一次变更的标准。STYLE.md 将此列为范本。

欢迎智能体撰写的拉取请求。

模板会询问智能体在何处提供了协助，以便审查者知道重点查看哪里。勾选此项不会导致任何提交被拒绝。
