What it checks

Six areas, weighted by what a launch loses.

A launch nobody can measure teaches you nothing, so measurement weighs most. A claim the code contradicts is the top comment on launch day, so claims come next.

Each area starts at 100. A FAIL costs 25 points and a WARN 10. Something it could not check costs nothing and is listed as unverified, so a missing repository lowers the confidence, not the score.

  • 85–100 Ready
  • 70–84 Ready after fixes
  • 55–69 Needs work
  • Below 55 Not ready
  1. 25Measurement

    Will the launch be recorded, down to the one action?

  2. 20Claims

    Does the product do what the page and the release notes say?

  3. 20Search

    Can search engines index and describe every key page?

  4. 15Social card

    Does a shared link show a title, a description and an image?

  5. 10Answer engines

    Can ChatGPT, Perplexity and Claude read and cite it?

  6. 10First impression

    Does the first screen say who it is for and what to do?

FAQ

Before you install it.

Which agents does it work with?

Any agent the open skills CLI installs into: Claude Code, Codex, Cursor, OpenCode, Gemini CLI, GitHub Copilot, Windsurf and Zed among them. The skill is one SKILL.md folder in the Agent Skills format, so an agent that reads that format can use it without the installer. Claude Code and Codex can also install it as a plugin from Duct's own catalogue, with the commands under the install box.

Does it send my site or my code to Duct?

No. The skill is a set of instructions your agent follows with its own web and shell tools. There is no Duct server in the loop, no account and no API key. What your agent reads goes only where your agent's requests always go: to the model you already use.

Will it change my code?

Not without a yes. The one file it writes on its own is its report, duct-launch-check.md. Each fix comes as a diff and a question, one at a time. It never commits, pushes or deploys, and it never opens .env or key files.

Do I need a repository open?

No, but it is better with one. Without the code it checks the live pages only, and most of the measurement area comes back unverified rather than failed. The findings a page audit cannot give, like a download that sends no event, come from the repository.

How is it different from an SEO audit?

An SEO audit reads the HTML. launch-check also reads the code behind it and checks what the page promises against what the product does. Search is one area of six. For a full crawl with keyword clusters and competitors, run Duct's free SEO audit.

What does it cost, and how long does it take?

The skill is free and MIT licensed. It runs on your agent's own model, so a check costs what your agent spends reading ten pages and part of a repository. It stops at ten pages and aims to finish in ten minutes.

Does the installer track anything?

The skills CLI, which is open source and not ours, counts installs anonymously for the skills.sh leaderboard. Set DISABLE_TELEMETRY=1 or DO_NOT_TRACK=1 before you run it to turn that off. The skill itself sends nothing anywhere.

How do I update or remove it?

npx skills update brings it to the latest version, and npx skills remove launch-check takes it out. The install goes into the project you run it in; add -g to make it available in every project. The CLI needs Node.js 22.20 or later.
