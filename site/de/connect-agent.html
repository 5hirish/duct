Einrichtung durch Agent

Sieben Agenten. Eine Adresse.

Jeder Agent verbindet sich mit demselben Server. Wähle deinen für die genauen Schritte aus.

Claude Code

  1. Führe in deinem Terminal aus: 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. Führe in Claude Code /mcp aus, wähle duct und dann Authentifizieren.
  3. Dein Browser öffnet sich in Duct. Klicke auf Zulassen.

Codex

  1. Führe in deinem Terminal aus: 
    codex mcp add duct --url https://api.getduct.ai/mcp
  2. Dann anmelden: 
    codex mcp login duct
  3. Dein Browser öffnet sich in Duct. Klicke auf Zulassen.

Cursor

  1. Füge Duct zu ~/.cursor/mcp.json hinzu: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Drücke in Cursors MCP-Einstellungen die Anmeldeaufforderung auf dem Duct-Server.
  3. Dein Browser öffnet sich in Duct. Klicke auf Zulassen.

VS Code

  1. Öffne die Befehlspalette und führe MCP: Server hinzufügen aus.
  2. Wähle HTTP, füge die Adresse ein und nenne es duct: 
    https://api.getduct.ai/mcp
  3. VS Code fordert dich zur Anmeldung auf, wenn es Duct zum ersten Mal verwendet. Dein Browser öffnet sich auf Duct. Klicke auf Zulassen.

OpenCode

  1. Füge Duct zu opencode.json hinzu: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Dann anmelden: 
    opencode mcp auth duct
  3. Dein Browser öffnet sich in Duct. Klicke auf Zulassen.

Claude, auf claude.ai oder Claude Desktop

  1. Öffne auf claude.ai oder in Claude Desktop Einstellungen → Connectors und wähle Benutzerdefinierten Connector hinzufügen.
  2. Nenne es Duct und füge die Adresse ein: 
    https://api.getduct.ai/mcp
  3. Drücke Verbinden. Duct öffnet sich in deinem Browser. Klicke auf Zulassen.

ChatGPT

  1. Aktiviere in ChatGPTs Einstellungen den Entwicklermodus.
  2. Füge einen Connector mit dieser Adresse hinzu und wähle OAuth zur Authentifizierung: 
    https://api.getduct.ai/mcp
  3. Duct öffnet sich in deinem Browser. Klicke auf „Zulassen“.

Ein anderer Agent? Wenn er einen entfernten MCP-Server über seine Adresse hinzufügen kann, gib ihm dieselbe. Wenn er sich nicht anmelden kann, verwende einen Token.

Was dein Agent tun kann

Es liest und erstellt Entwürfe. Du entscheidest.

Duct gibt deinem Agenten heute drei Tools. Freigeben, Anwenden und Verbinden bleiben bei dir, in Duct.

Dein Agent kann
  • Liste deine Projekte auf.
  • Lies ein Projekt.
  • Entwirf die Beschreibung, Zielgruppe und Wettbewerber eines Projekts aus deinem Repo oder deinen Dateien.
Es kann niemals
  • Änderungen freigeben oder anwenden.
  • Tools verbinden.
  • Siehe Schlüssel oder Anmeldeinformationen.
  • Überschreibe, was du in Duct eingegeben hast. Ein Entwurf füllt nur Lücken oder ersetzt einen früheren Entwurf.

Jede Änderung wird in der Projektaktivität angezeigt.

Zugriff

Jeder Agent ist aufgelistet. Trenne einen beliebigen.

Du siehst jeden verbundenen Agenten

Öffne in Duct Einstellungen → Verbinde deinen KI-Agenten. Jeder von dir zugelassene Agent ist dort, und du kannst ihn trennen. Ein getrennter Agent stoppt bei seinem nächsten Aufruf.

Kein Browser? Verwende ein Token.

Für CI, eine Remote-Maschine oder einen Agenten ohne Anmeldung. Erstelle einen auf derselben Einstellungsseite, unter „Kein Browser? Verwende ein Token.“ Dein Agent sendet es als Header:

Authorization: Bearer duct_mcp_…

In Claude Code:

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

Fehlerbehebung

Steckst du fest? Beginne hier.

Mein Browser hat sich nie geöffnet

Starte die Anmeldung selbst: führe /mcp in Claude Code, codex mcp login duct in Codex oder opencode mcp auth duct in OpenCode aus.

Es meldet, dass es sich nicht registrieren konnte, oder „unterstützt keine dynamische Client-Registrierung“

Aktualisiere deinen Agenten auf die neueste Version und versuche es erneut. Wenn es immer noch fehlschlägt, verbinde dich stattdessen mit einem Token.

Es hat funktioniert, und jetzt erhält es einen 401-Fehler

Du hast die Verbindung in Duct getrennt, oder die Anmeldung ist nach 90 Tagen Inaktivität abgelaufen. Melde dich erneut über deinen Agenten an.

Ich bat es, das Projekt einzurichten, und nichts änderte sich

Ein Entwurf überschreibt niemals, was du in Duct eingegeben hast. Er füllt nur leere Felder aus oder ersetzt einen früheren Entwurf. Prüfe die Projektseite in Duct.

Ich hoste Duct selbst

Verwende deine eigene API-Adresse gefolgt von /mcp, anstelle von https://api.getduct.ai/mcp.
