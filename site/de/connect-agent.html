Du wählst aus

Ein Projekt einrichten oder gemeinsam mit dir arbeiten.

Wenn sich dein Agent anmeldet, wählst du aus, was er tun darf und in welchen Projekten. Ändere dies jederzeit in den Einstellungen.

  • Hilf beim Einrichten meiner Projekte. Es erstellt Entwürfe für Beschreibung, Zielgruppe und Mitbewerber deines Projekts aus deinem Repo.
  • Arbeite an meiner Seite. Es liest auch deine Tools, merkt sich, was wichtig ist, und schreibt Briefings. Vorgeschlagene Änderungen, Beitragsentwürfe und Bilder über deine eigenen Schlüssel bleiben deaktiviert, bis du sie einschaltest.
  • Alle deine Projekte oder nur die, die du auswählst.

Liegt nie beim Agent, egal was du erlaubst: das Freigeben oder Anwenden einer Änderung, Veröffentlichen, Verbinden eines Tools, deine Passwörter und Schlüssel. Alles, was er speichert, wird in der Aktivität unter seinem Namen angezeigt, und jede Änderung kann mit einem Klick rückgängig gemacht werden.

Einrichtung durch Agenten

Acht Agents. Eine Adresse.

Jeder Agent verbindet sich mit derselben Adresse. Wähle deinen.

Claude Code

  1. Führe in deinem Terminal aus: 
    claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp
  2. Führe in Claude Code /mcp aus, wähle duct und dann Authenticate.
  3. Wähle im Browser aus, was er tun darf, und klicke dann auf Zulassen.
  4. Führe /mcp__duct__insights_brief für das Briefing-Playbook von Duct aus oder frage einfach.

Codex

  1. Führe in deinem Terminal aus: 
    codex mcp add duct --url https://mcp.getduct.ai/mcp
  2. Melde dich dann an: 
    codex mcp login duct
  3. Wähle im Browser aus, was er tun darf, und klicke dann auf Zulassen.

Cursor

  1. Duct zu ~/.cursor/mcp.json hinzufügen: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Klicke in den MCP-Einstellungen von Cursor bei duct auf Login.
  3. Wähle im Browser aus, was er tun darf, und klicke dann auf Zulassen.

Gemini CLI

  1. Duct zu ~/.gemini/settings.json hinzufügen: 
    {
  "mcpServers": {
    "duct": {
      "httpUrl": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Starte Gemini CLI und melde dich an: 
    /mcp auth duct
  3. Wähle im Browser aus, was er tun darf, und klicke dann auf Zulassen.
  4. Führe /insights_brief für das Briefing-Playbook von Duct aus oder frage einfach.

VS Code

  1. Öffne die Befehlspalette und führe MCP: Add Server aus.
  2. Wähle HTTP, füge die Adresse ein und nenne es duct: 
    https://mcp.getduct.ai/mcp
  3. VS Code fordert dich beim ersten Mal zum Anmelden auf. Wähle in deinem Browser aus, was er tun darf, und klicke dann auf Zulassen.

OpenCode

  1. Duct zu opencode.json hinzufügen: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Melde dich dann an: 
    opencode mcp auth duct
  3. Wähle im Browser aus, was er tun darf, und klicke dann auf Zulassen.

Claude, auf claude.ai oder Claude Desktop

  1. Öffne Einstellungen → Connectors und wähle „Benutzerdefinierten Connector hinzufügen“.
  2. Nenne es Duct und füge die Adresse ein: 
    https://mcp.getduct.ai/mcp
  3. Klicke auf Verbinden. Wähle im Browser aus, was er tun darf, und klicke dann auf Zulassen.

ChatGPT

  1. Aktiviere in ChatGPTs Einstellungen den Entwicklermodus.
  2. Füge einen Connector mit dieser Adresse und OAuth-Anmeldung hinzu: 
    https://mcp.getduct.ai/mcp
  3. Wähle im Browser aus, was er tun darf, und klicke dann auf Zulassen.

Ein anderer Agent? Gib ihm dieselbe Adresse oder nutze ein Token, wenn er sich nicht anmelden kann.

Kein Browser? Verwende ein Token.

Für CI oder einen Remote-Server. Erstelle eines unter Einstellungen → KI-Agent verbinden mit denselben Optionen. Diese Seite listet auch jeden Agent auf, den du erlaubt hast, und trennt jeden einzelnen. Sende es als Header:

Authorization: Bearer duct_mcp_…

In Claude Code:

claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

Fragen

Was häufig gefragt wird. Dann die Behebungen.

Bevor du verbindest

Brauche ich einen API-Schlüssel?

Nein. Es läuft über den Tarif, den du bereits bezahlst. Ein gespeicherter Schlüssel wird nur für Bilder und geplante Briefings benötigt.

Welche meiner Tools kann er lesen?

Stripe, Meta Ads, Mixpanel, GitHub, RevenueCat und den Rest verbindest du in Duct. Google Analytics, Search Console, Ads und Tag Manager bleiben vorerst bei Ducts eigenem Agenten, während die Richtlinien von Google für externe Assistenten bestätigt werden.

Kann er mein Werbekonto ändern?

Nur als Vorschlag, wenn du das aktivierst. Er wartet in Duct, bis du ihn freigibst. Kein Agent kann eine Änderung anwenden.

Sieht Duct meine Unterhaltung?

Nein. Duct sieht nur die Aufrufe, die dein Agent an Duct richtet, niemals den Rest deines Chats.

Wird ein Briefing ausgeführt, während mein Laptop zugeklappt ist?

Nicht von deinem Agenten. Geplante Briefings laufen in Duct mit einem gespeicherten Schlüssel, weil niemands Agent um 3 Uhr nachts läuft.

Wenn etwas schiefgeht

Mein Browser hat sich nie geöffnet

Starte es selbst: /mcp in Claude Code, codex mcp login duct, /mcp auth duct in Gemini CLI oder opencode mcp auth duct.

Es meldet, dass es sich nicht registrieren konnte, oder „unterstützt keine dynamische Client-Registrierung“

Aktualisiere deinen Agenten und versuche es erneut. Wenn es weiterhin fehlschlägt, verwende ein Token.

Es hat funktioniert, und jetzt erhält es einen 401-Fehler

Die Verbindung wurde getrennt oder 90 Tage lang nicht genutzt. Melde dich über deinen Agenten erneut an.

Ein erwartetes Tool ist nicht da

Er sieht nur, was du erlaubt hast. Trenne ihn in Duct, verbinde ihn erneut und wähle Work alongside me.

Ich hoste Duct selbst

Verwende deine eigene API-Adresse gefolgt von /mcp.
