Zum Inhalt springen

Nutze Duct von deinem Agenten aus. Kein Token zum Kopieren.

Füge eine Adresse in deinen Agenten ein, klicke einmal auf Zulassen, und er kann deine Duct-Projekte lesen und Entwürfe dafür erstellen.

https://api.getduct.ai/mcp

Einrichtung für

  • Claude Code
  • Codex
  • Cursor
  • VS Code
  • OpenCode
  • Claude

Wähle deinen Agenten aus. Füge eine Zeile ein.

Claude Code

  1. Führe dies in deinem Terminal aus: 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. Führe in Claude Code /mcp aus, wähle duct, wähle Authentifizieren und klicke auf Erlauben.

Codex

  1. Führe diese in deinem Terminal aus: 
    codex mcp add duct --url https://api.getduct.ai/mcp
    codex mcp login duct
  2. Dein Browser öffnet sich in Duct. Klicke auf Zulassen.

Cursor

  1. Füge dies zu ~/.cursor/mcp.json hinzu: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Melde dich in den MCP-Einstellungen von Cursor bei duct an und klicke auf Erlauben.

VS Code

  1. Führe in der Befehlspalette MCP: Server hinzufügen aus, wähle HTTP und füge ein: 
    https://api.getduct.ai/mcp
  2. Nenne es duct. Klicke beim ersten Mal, wenn es Duct nutzt, im Browser auf Zulassen.

OpenCode

  1. Führe diese in deinem Terminal aus: 
    opencode mcp add duct --global --url https://api.getduct.ai/mcp
    opencode mcp auth duct
  2. Dein Browser öffnet sich in Duct. Klicke auf Zulassen.

Claude, auf claude.ai oder Claude Desktop

  1. Wähle unter Einstellungen → Connectors „Benutzerdefinierten Connector hinzufügen“, nenne ihn Duct und füge ein: 
    https://api.getduct.ai/mcp
  2. Klicke auf Verbinden, dann auf Zulassen.

ChatGPT

  1. Aktiviere in ChatGPTs Einstellungen den Entwicklermodus.
  2. Füge einen Connector mit OAuth und dieser Adresse hinzu: 
    https://api.getduct.ai/mcp
  3. Dein Browser öffnet sich in Duct. Klicke auf Zulassen.

Ein anderer Agent? Jeder, der einen Remote-MCP-Server über eine Adresse hinzufügt, funktioniert. Wenn er sich nicht anmelden kann, nutze ein Token.

Frage ihn dann in einfachen Worten.

Es liest deine Projekte aus deinem Repo oder deinen Dateien und erstellt Entwürfe dafür. Du kannst jede Bearbeitung in Duct rückgängig machen.

Es kann niemals Änderungen an deinen Tools freigeben oder anwenden, neue verbinden oder deine Schlüssel sehen.

  • Richte dieses Produkt in Duct ein.

    draft_projectEntwirft den Pitch, die Zielgruppe und die Mitbewerber. Was du eingegeben hast, bleibt bestehen.

  • Was weiß Duct über unsere Zielgruppe?

    get_projectLiest das Projekt und woher jede Antwort stammt.

  • Entferne Acme aus unseren Mitbewerbern.

    update_projectÄndert nur, worum du gebeten hast. Macht es in Aktivität rückgängig.

Sieh alle Agenten. Trenne jeden einzelnen.

In Duct unter Einstellungen → KI-Agenten verbinden wird jeder zugelassene Agent aufgelistet. Wenn du einen trennst, stoppt er bei seinem nächsten Aufruf.

Kein Browser? Verwende ein Token.

Für CI oder einen Remote-Rechner. Erstelle ein Token auf derselben Einstellungsseite; dein Agent sendet es als Header.

Authorization: Bearer duct_mcp_…

In Claude Code:

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

Du kommst nicht weiter? Starte hier.

Mein Browser hat sich nie geöffnet

Starte die Anmeldung selbst: führe /mcp in Claude Code, codex mcp login duct in Codex oder opencode mcp auth duct in OpenCode aus.

Es meldet, dass es sich nicht registrieren konnte, oder „unterstützt keine dynamische Client-Registrierung“

Aktualisiere deinen Agenten auf die neueste Version und versuche es erneut. Wenn es immer noch fehlschlägt, verbinde dich stattdessen mit einem Token.

Es hat funktioniert, und jetzt erhält es einen 401-Fehler

Du hast die Verbindung in Duct getrennt, oder die Anmeldung ist nach 90 Tagen Inaktivität abgelaufen. Melde dich erneut über deinen Agenten an.

Ich bat es, das Projekt einzurichten, und nichts änderte sich

Ein Entwurf überschreibt nie, was du in Duct eingegeben hast. Er füllt nur leere Felder aus oder ersetzt einen früheren Entwurf. Um ein von dir festgelegtes Feld zu ändern, fordere diese Bearbeitung namentlich an.
