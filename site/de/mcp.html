Fragen und was ein Fehler bedeutet

Es steht „Duct verbindet sich nur mit Servern im öffentlichen Internet“

Die Adresse zeigt auf deinen eigenen Computer oder ein privates Netzwerk. Duct ruft Server aus der Cloud auf und erreicht daher nur öffentliche HTTPS-Adressen. Server, die lokal über stdio laufen, funktionieren ebenfalls nicht.

Es fragt nach einem API-Key

Der Server bietet keine Ein-Klick-Anmeldung, die Duct nutzen kann. Erstelle einen Schlüssel in den Einstellungen des Anbieters und füge ihn im selben Dialog ein. Duct speichert ihn verschlüsselt und sendet ihn nur an diesen Server.

Es steht „Muss neu verbunden werden“

Die Anmeldung ist abgelaufen oder wurde seitens des Anbieters widerrufen. Drücke Erneut verbinden im Werkzeugkasten und melde dich erneut an.

Sieht das Modell meine Keys?

Nein. Anmeldungen und Keys bleiben auf der Seite von Duct verschlüsselt und werden mit dem Aufruf übertragen. Was ein Server zurücksendet, wird als Daten gelesen, niemals als Anweisungen.

Können Personen, mit denen ich ein Projekt teile, meine Server nutzen?

Nein. Ein Server gehört der Person, die ihn verbunden hat, und nur ihre eigenen Chats nutzen ihn. Teammitglieder verbinden ihre eigenen.

Kostet ein Tool-Aufruf etwas?

Manche tun das, beim Anbieter. Ein OpenSEO-Rechercheaufruf verbraucht deine OpenSEO-Credits, genauso wie in jeder anderen App.

Wie unterscheidet sich das von Connectoren für Claude oder ChatGPT?

Ihre Verzeichnisse listen größtenteils dieselben Anbieter-Server auf. Duct verbindet sich direkt mit diesen Servern, egal welches Modell du mitbringst.
