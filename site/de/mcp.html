Jeder andere Server

Nicht auf der Liste? Adresse einfügen.

Duct verbindet sich mit jedem MCP-Server, den es über das öffentliche Internet erreichen kann. Hier ist, was dazu nötig ist und was nicht funktioniert.

Verbindungen
  • Eine öffentliche https://-Adresse, die MCP über Streamable HTTP bereitstellt.
  • Ein-Klick-Anmeldung, wenn der Server OAuth Discovery veröffentlicht und entweder ein Client-Metadaten-Dokument akzeptiert oder eine dynamische Client-Registrierung erlaubt.
  • Andernfalls ein von dir eingefügter API-Schlüssel, der als Bearer-Token an den Server gesendet wird.
Nicht unterstützt
  • Lokale Server, die über Stdio auf deinem eigenen Computer laufen.
  • Server in einem privaten Netzwerk. Der gehostete Dienst ruft nur öffentliche Internetadressen auf.
  • Anbieter, die nur vorab genehmigte Clients zulassen. Figma und Slack funktionieren heute so.

Was der Agent tun wird und nicht.

Schreibgeschützte Läufe. Alles andere fragt zuerst.

Für jeden Server, den du verbindest, gelten dieselben Regeln, mit einem Unterschied: Ein Server, den du über seine Adresse hinzufügst, fragt vor jedem Aufruf.

Schreibgeschützte Tools laufen sofort

Wenn einer der vorgefertigten Server ein Tool als schreibgeschützt markiert, ruft der Agent es auf, ohne vorher zu fragen. Ein Server, den du per Adresse hinzufügst, erhält dieses Vertrauen nicht: Duct hat ihn nicht geprüft, daher fragt jeder Aufruf zuerst.

Alles andere wartet auf dich

Jeder andere Aufruf pausiert und zeigt dir alles, was er senden wird. Gib es frei oder überspringe es.

Antworten sind Daten, keine Befehle

Was ein Server zurücksendet, wird als zu lesende Daten behandelt, niemals als zu befolgende Anweisungen.

Deine Tokens erreichen das Modell nie

Anmeldungen und API-Schlüssel bleiben auf der Seite von Duct, verschlüsselt, und werden dem Modell nie gezeigt.

Deine Server, deine Chats

Ein Server gehört der Person, die ihn verbunden hat, und nur ihre eigenen Chats nutzen ihn, in jedem Projekt. Jemand, mit dem du ein Projekt teilst, verbindet seinen eigenen und liest niemals deine durch.

Vorerst der Erkenntnisse-Chat

Heute werden verbundene Server im Erkenntnisse-Chat verwendet. Geplante Briefings und Content Studio rufen sie noch nicht auf.

Fehlerbehebung

Wenn ein Server Nein sagt.

Es steht „Dieser Server benötigt einen API-Schlüssel“

Der Server bietet keine Anmeldung, die Duct nutzen kann. Erstelle einen API-Schlüssel in den Einstellungen des Anbieters und füge ihn unter Verbindungen ein.

Es steht „Muss neu verbunden werden“

Die Anmeldung ist abgelaufen oder wurde auf Seiten des Anbieters widerrufen. Drücke auf Verbindungen auf Neu verbinden und melde dich erneut an.

Es steht „Duct verbindet sich nur mit Servern im öffentlichen Internet“

Die Adresse zeigt auf deinen eigenen Computer oder ein privates Netzwerk. Der gehostete Dienst ruft nur öffentliche Internetadressen auf, daher kann ein lokaler oder interner Server nicht erreicht werden.

Warum kann ich Figma oder Slack nicht verbinden?

Beide lassen nur Clients zu, die sie im Voraus genehmigt haben, daher reicht ihre Serveradresse allein nicht aus. Sie funktionieren noch nicht mit Duct.

Kostet ein Tool-Aufruf etwas?

Manche tun das, auf Seiten des Anbieters. Ein Aufruf, der dort Credits kostet, wie OpenSEO-Recherche, verbraucht deine Credits bei diesem Anbieter, genau wie von jedem anderen Client.

Wie sich dies auf Claude- und ChatGPT-Connectors bezieht

Ihre Verzeichnisse listen meist dieselben Anbieter-MCP-Server auf. Duct verbindet sich direkt mit diesen Servern, mit jedem Modell, das du mitbringst.
