Tag Manager, mit dem zuerst benannten Zurücknehmen.

Wissen

Was Duct bereits weiß über Tag Manager

  1. 01

    Nichts ist live, bis es veröffentlicht wird.

    Bearbeitungen in einem Arbeitsbereich ändern nichts auf deiner Website. Duct bereitet seine Änderungen dort vor, und die Veröffentlichung, die den Live-Container für jeden Besucher ersetzt, wartet immer auf dich.

  2. 02

    Das Zurücknahme-Ziel wird zuerst gelesen.

    Vor einer Veröffentlichung zeichnet Duct die Live-Version auf, sodass ein Rollback genau das wieder veröffentlicht, was da war.

  3. 03

    Ein Tag, der ausgelöst wird, kann trotzdem kaputt sein.

    Ein Tag kann auf jeder Seite ausgelöst werden und nichts Nützliches senden. Duct prüft, was in GA4 oder Mixpanel angekommen ist, nicht den Auslösestatus.

  4. 04

    Umbenennungen folgen keinen Referenzen.

    Das Umbenennen einer Variable über die API lässt jeden Tag auf den alten Namen zeigen. Duct patcht die Tags in derselben Änderung oder benennt nicht um.

Einrichtung

Tag Manager in drei Schritten verbinden

  1. 1

    In Duct, öffne Verbindungen und wähle Google Tag Manager.

  2. 2

    Mit Google anmelden und Zugriff zum Bearbeiten und Veröffentlichen von Containern erlauben.

  3. 3

    Wähle den Container, den dieses Projekt verwendet.

Duct fragt nach Bearbeitungs- und Veröffentlichungszugriff, wenn du dich anmeldest, da beides zur Reparatur eines Tags benötigt wird. Bearbeitungen bleiben in einem Arbeitsbereich, und eine Veröffentlichung wartet immer auf dein Anwenden.

Schlüssel und Tokens werden verschlüsselt von Ducts gehosteter API gespeichert, niemals in deinem Browser, und du kannst eine Verbindung jederzeit entfernen. Ein Self-Host-Build speichert sie auf deiner eigenen Maschine.

FAQ

Tag Manager, beantwortet

Was kann Duct im Tag Manager ändern?

Vier: GTM-Tag erstellen/aktualisieren (Arbeitsbereich), GTM-Variable erstellen/aktualisieren (Arbeitsbereich), GTM-Container-Version veröffentlichen und eine ältere GTM-Version erneut veröffentlichen. Standardmäßig wartet jede auf dein Anwenden, und jede kann zurückgenommen werden.

Wird Duct eigenständig auf meiner Live-Website veröffentlichen?

Nein. Eine Veröffentlichung ersetzt den Live-Container für jeden Besucher, daher wartet sie immer auf dich, unabhängig von der Autonomie des Projekts. Arbeitsbereich-Bearbeitungen können im unterstützten Modus eigenständig angewendet werden, und sie ändern nichts live, bis eine Veröffentlichung erfolgt.

Wie funktioniert Zurücknehmen?

Bevor es veröffentlicht, speichert Duct die aktuelle Version. Zurücknehmen veröffentlicht diese Version erneut, und das Aktivitätsprotokoll zeigt beides.

Ist es kostenlos?

Ja. Duct ist kostenlos mit deinen eigenen Modell-Keys oder dem ChatGPT-Plan, den du bereits hast, und der Kern ist MIT-lizenziert. Ein kostenpflichtiger Plan bündelt später die Modelle; nichts, was heute offen ist, wird dahinter verschoben. Was Geld kosten wird.
