FAQ

Connectors, beantwortet

Mit welchen Tools verbindet sich Duct?

Google Ads, Meta Ads, Apple Search Ads, ChatGPT Ads, Google Analytics 4, Google Search Console, Google Tag Manager, Mixpanel, Microsoft Clarity, GrowthBook, GitHub, Stripe und RevenueCat. Die vier Google-Tools verbinden sich, wenn du dich mit Google anmeldest; der Rest benötigt einen Schlüssel, den du einmal einfügst. HubSpot ist als Nächstes dran.

Benötigt Duct Schreibzugriff auf meine Konten?

Nein. Antworten und Briefings funktionieren überall mit Lesezugriff. Vier Connectors können auch Änderungen vornehmen (Google Ads, GA4, Tag Manager und Mixpanel), insgesamt 20 Arten, und standardmäßig wartet jede auf dein Anwenden.

Wo werden meine Connector-Zugangsdaten gespeichert?

Schlüssel und Tokens werden verschlüsselt von Ducts gehosteter API gespeichert, niemals in deinem Browser, und du kannst eine Verbindung jederzeit entfernen. Ein Self-Host-Build speichert sie auf deiner eigenen Maschine.

Kann ich einen Connector anfragen?

Ja. Öffne eine Diskussion auf GitHub, nenne das Tool und die Frage, die es beantworten soll. Connectors werden gebaut, wenn eine Frage einen benötigt.

Hat Duct einen MCP-Server?

Noch nicht. Ein MCP-Server, damit Claude, Cursor und andere Agents die Connectors von Duct nutzen können, ist in Issue #197 geplant.
