Wissen

Was Duct bereits weiß über ChatGPT Ads

  1. 01

    Die Ads API kann keine Conversions sehen.

    Seine Metriken sind Impressionen, Klicks, Ausgaben, CTR, CPC und CPM. Pixel-Conversions werden nur im Ads Manager angezeigt, daher bewertet Duct den Kanal niemals allein nach dem CPC. Es prüft Stripe.

  2. 02

    Zwei Einheiten von einem Anbieter.

    Insights melden Ausgaben als Dezimalzahl (18.42); der Pixel meldet Cents (1499). Das Mischen ist ein 100× Fehler, daher konvertiert Duct, bevor es vergleicht.

  3. 03

    Ein Schlüssel, ein Anzeigenkonto.

    Ein Ads-API-Schlüssel erreicht genau ein Werbekonto. Duct liest zuerst, welches es ist, sodass ein Schlüssel vom falschen Konto dies anzeigt, anstatt leer auszusehen.

  4. 04

    Nur der Rechnungssteller weiß es.

    Jede Anzeigenplattform meldet Conversions, die sie sich selbst zuschreibt. Duct gleicht sie mit Stripe ab, niemals miteinander.

Einrichtung

Verbinde ChatGPT Ads in drei Schritten

  1. 1

    Im OpenAI Ads Manager erstellst du einen Ads API Schlüssel für das Anzeigenkonto, das du lesen möchtest.

  2. 2

    In Duct öffnest du Verbindungen, wählst OpenAI Ads und fügst den Schlüssel ein.

  3. 3

    Duct zeigt, zu welchem Anzeigenkonto der Schlüssel gehört, und liest dann dessen Kampagnen und tägliche Summen.

Ein Ads-API-Schlüssel ist auf ein Werbekonto beschränkt, und OpenAI gewährt API-Zugriff pro Konto, während die API in der Beta-Phase ist. Duct verwendet den Schlüssel nur zum Lesen; es hat keine ChatGPT Ads-Änderungsoperation.

Schlüssel und Tokens werden verschlüsselt von Ducts gehosteter API gespeichert, niemals in deinem Browser, und du kannst eine Verbindung jederzeit entfernen. Ein Self-Host-Build speichert sie auf deiner eigenen Maschine.

FAQ

ChatGPT Ads, beantwortet

Kann Duct ChatGPT Ads-Conversions sehen?

Nein, weil die OpenAI Ads API sie nicht meldet; Pixel-Conversions werden nur im Ads Manager angezeigt. Duct misst den Kanal an dem, was Stripe abgerechnet und GA4 gesehen hat, was ohnehin die Zahl ist, die das Budget bestimmt.

Ändert Duct meine ChatGPT Ads Kampagnen?

Nein. Der Connector ist schreibgeschützt. Duct kann empfehlen, Budget zwischen Kampagnen oder Kanälen zu verschieben; du nimmst die Änderung im Ads Manager vor.

Sind ChatGPT Ads und OpenAI Ads dasselbe?

Ja. OpenAI verkauft die Anzeigen, die in ChatGPT laufen, über seinen Ads Manager und die Ads API. Die Duct App listet den Connector als OpenAI Ads.

Ist es kostenlos?

Ja. Duct ist kostenlos mit deinen eigenen Modell-Keys oder dem ChatGPT-Plan, den du bereits hast, und der Kern ist MIT-lizenziert. Ein kostenpflichtiger Plan bündelt später die Modelle; nichts, was heute offen ist, wird dahinter verschoben. Was Geld kosten wird.
