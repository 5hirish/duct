Der Agent schlägt vor. Du gibst frei.

Duct kann eine Änderung an deinen Ads oder Analytics vorbereiten. Kein Tool erlaubt es ihm, eine freizugeben, also kann man es nicht dazu überreden.

Alles Destruktive wartet auf deinen Klick, bei jeder Einstellung.

Eine kurze Liste umkehrbarer Änderungen kann sich von selbst anwenden, und nur wenn du das aktivierst.

Miete das Agent-Framework. Heirate es niemals.

Agenten-Frameworks ändern sich jede Woche. Die Prompts, Werkzeuge und das Scoring von Duct sind einfaches Python, und ein Test schlägt fehl, wenn ein Framework-Import außerhalb der wenigen Adapterdateien erscheint.

Abstrahiere bei der zweiten Nutzung.

Eine Implementierung ist eine Vermutung. Zwei sind eine Tatsache. Die geteilten Adapter wurden herausgezogen, als ein zweiter Agent sie brauchte, und die Allowlist sagt, welcher.

Ein API-Schlüssel ist keine Berechtigung.

Der Key der App wird an den Browser geliefert, belegt also, welche App anruft, nie wer. Jede Projekt-Route prüft, ob du Mitglied bist, und Fremde erhalten einen 404-Fehler.

Ein Test durchläuft jede Route und schlägt bei einer ohne angemeldeten Benutzer fehl, es sei denn, eine schriftliche Begründung steht daneben.

Deine Keys, deine Modellwahl.

Bringe einen Key von Anthropic, OpenAI, Google, xAI oder OpenRouter mit oder führe ein lokales Modell aus. Du wählst drei Modelle; Duct entscheidet, welche Aufgabe welches braucht.

Die Desktop-App speichert deine Keys im Schlüsselbund deines Betriebssystems. Um gar keine Duct-Server zu nutzen, führt der Self-Host-Build das gesamte Backend auf deinem Rechner aus.

Kommentare enthalten das Warum.

Ein Kommentar, der die Zeile darunter wiederholt, lehrt Leute, Kommentare zu überspringen. Diejenigen, die es wert sind, geschrieben zu werden, nennen die Bedrohung, den Fehler oder die Option, die verloren hat.

In Code, den Agenten mit schreiben, wird die nächste Änderung an dieser Begründung gemessen. STYLE.md führt dies als Vorbild an.

Von Agenten geschriebene Pull-Requests sind willkommen.

Die Vorlage fragt, wo ein Agent geholfen hat, damit Reviewer wissen, wo sie am genauesten hinschauen müssen. Nichts wird abgelehnt, nur weil es angekreuzt ist.

Stimmst du nicht zu? Sag es öffentlich.

Jedes davon ist ein Standard mit einem Grund. Wenn der Grund falsch ist, sollte sich der Grund ändern.
