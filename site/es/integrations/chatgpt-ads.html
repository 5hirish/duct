Conocimiento

Lo que Duct ya sabe sobre ChatGPT Ads

  1. 01

    La API de Ads no puede ver las conversiones.

    Sus métricas son impresiones, clics, gasto, CTR, CPC y CPM. Las conversiones de píxel solo se muestran en Ads Manager, por lo que Duct nunca considera que el canal es bueno solo por el CPC. Comprueba Stripe.

  2. 02

    Dos unidades de un proveedor.

    Los hallazgos informan el gasto como un decimal (18.42); el píxel informa los céntimos (1499). Mezclarlos es un error de 100×, así que Duct convierte antes de comparar.

  3. 03

    Una clave, una cuenta publicitaria.

    Una clave API de anuncios accede exactamente a una cuenta publicitaria. Duct lee cuál es primero, así que una clave de la cuenta incorrecta lo indica en lugar de aparecer vacía.

  4. 04

    Solo el facturador lo sabe.

    Cada plataforma publicitaria informa las conversiones que se atribuye a sí misma. Duct las concilia con Stripe, nunca entre sí.

Configuración

Conecta ChatGPT Ads en tres pasos

  1. 1

    En OpenAI Ads Manager, crea una clave de API de Ads para la cuenta publicitaria que deseas leer.

  2. 2

    En Duct, abre Conexiones, elige OpenAI Ads y pega la clave.

  3. 3

    Duct muestra a qué cuenta publicitaria pertenece la clave, luego lee sus campañas y totales diarios.

Una clave API de anuncios está limitada a una cuenta publicitaria, y OpenAI otorga acceso a la API por cuenta mientras la API está en beta. Duct usa la clave solo para leer; no tiene operaciones de cambio para ChatGPT Ads.

Las claves y tokens se almacenan cifrados por la API alojada de Duct, nunca en tu navegador, y puedes eliminar una conexión en cualquier momento. Una versión autoalojada los mantiene en tu propia máquina.

FAQ

ChatGPT Ads, respondido

¿Puede Duct ver las conversiones de ChatGPT Ads?

No, porque la API de OpenAI Ads no las informa; las conversiones de píxel solo se muestran en Ads Manager. Duct mide el canal contra lo que Stripe liquidó y lo que GA4 vio, que es el número que de todos modos decide el presupuesto.

¿Duct cambia mis campañas de ChatGPT Ads?

No. El conector es de solo lectura. Duct puede recomendar mover el presupuesto entre campañas o canales; tú haces el cambio en Ads Manager.

¿Son ChatGPT Ads y OpenAI Ads lo mismo?

Sí. OpenAI vende los anuncios que se ejecutan en ChatGPT a través de su Ads Manager y Ads API. La app de Duct lista el conector como OpenAI Ads.

¿Es gratis?

Sí. Duct es gratis con tus propias claves de modelo o el plan de ChatGPT que ya tienes, y el núcleo tiene licencia MIT. Un plan de pago posterior agrupará los modelos; nada de lo que es abierto hoy pasará a ser de pago. Qué costará dinero.
