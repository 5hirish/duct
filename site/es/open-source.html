Cinco comandos desde una carpeta vacía para tener Duct en tu equipo. El README cubre el resto.

terminal
$ git clone https://github.com/5hirish/duct.git && cd duct
$ make setup
$ cp backend/.env.example backend/.env.local   # add one model provider key
$ make serve-backend                            # then, in a second terminal:
$ make serve-app

Preguntas frecuentes

¿Es Duct realmente gratis?

Sí. Duct tiene licencia MIT y es gratis con tus propias claves de modelo. Pagas directamente a tu proveedor de modelos o inicias sesión con el plan de ChatGPT que ya tengas.

¿Puedo ejecutar Duct sin una cuenta?

Sí. Clona el repositorio, ejecuta make setup, añade una clave de modelo e inicia el backend y la app. No interviene ninguna cuenta de Duct.

¿A qué renuncio al autoalojar?

Google Ads, GA4 y Search Console necesitan tu propio cliente de Google OAuth antes de conectarse, y la base de datos, las copias de seguridad y las actualizaciones las gestionas tú.

¿Puedo usar Duct comercialmente o bifurcarlo?

Sí. La licencia MIT permite el uso comercial, las modificaciones y la redistribución. Las excepciones son la documentación de terceros bajo docs/guides y el nombre y la marca de Duct.

¿Cómo contribuyo?

Empieza por CONTRIBUTING.md. El mapa de ruta es un panel público y cualquier pull request escrita con un agente es bienvenida si indica en qué ayudó el agente.

Léelo antes de conectar nada.
