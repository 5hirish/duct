Configuración por agente

Siete agentes. Una dirección.

Cada agente se conecta al mismo servidor. Elige el tuyo para ver los pasos exactos.

Claude Code

  1. En tu terminal, ejecuta: 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. En Claude Code, ejecuta /mcp, selecciona duct y elige Autenticar.
  3. Tu navegador se abre en Duct. Haz clic en Permitir.

Codex

  1. En tu terminal, ejecuta: 
    codex mcp add duct --url https://api.getduct.ai/mcp
  2. Luego inicia sesión: 
    codex mcp login duct
  3. Tu navegador se abre en Duct. Haz clic en Permitir.

Cursor

  1. Añade Duct a ~/.cursor/mcp.json: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. En la configuración MCP de Cursor, pulsa la solicitud de inicio de sesión en el servidor de duct.
  3. Tu navegador se abre en Duct. Haz clic en Permitir.

VS Code

  1. Abre la Paleta de comandos y ejecuta MCP: Add Server.
  2. Elige HTTP, pega la dirección y nómbralo duct: 
    https://api.getduct.ai/mcp
  3. VS Code te pide que inicies sesión la primera vez que usa Duct. Tu navegador se abre en Duct. Haz clic en Permitir.

OpenCode

  1. Añade Duct a opencode.json: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. Luego inicia sesión: 
    opencode mcp auth duct
  3. Tu navegador se abre en Duct. Haz clic en Permitir.

Claude, en claude.ai o Claude Desktop

  1. En claude.ai o en Claude Desktop, abre Ajustes → Conectores y elige Añadir conector personalizado.
  2. Nómbralo Duct y pega la dirección: 
    https://api.getduct.ai/mcp
  3. Pulsa Conectar. Duct se abre en tu navegador. Haz clic en Permitir.

ChatGPT

  1. En la configuración de ChatGPT, activa el modo de desarrollador.
  2. Añade un conector con esta dirección, y elige OAuth para la autenticación: 
    https://api.getduct.ai/mcp
  3. Duct se abre en tu navegador. Haz clic en Permitir.

¿Otro agente? Si puede añadir un servidor MCP remoto por su dirección, dale la misma. Si no puede iniciar sesión, usa un token.

Lo que tu agente puede hacer

Lee y redacta. Tú decides.

Duct le da a tu agente tres herramientas hoy. Aprobar, aplicar y conectar se quedan contigo, en Duct.

Tu agente puede
  • Enumera tus proyectos.
  • Lee un proyecto.
  • Redacta la descripción, audiencia y competidores de un proyecto desde tu repositorio o archivos.
Nunca puede
  • Aprobar o aplicar cambios.
  • Conecta herramientas.
  • Ver claves o credenciales.
  • Sobrescribe lo que escribiste en Duct. Un borrador solo rellena espacios en blanco o reemplaza un borrador anterior.

Cada cambio se muestra en la actividad del proyecto.

Acceso

Cada agente está listado. Desconecta cualquiera.

Ves cada agente conectado

En Duct, abre Ajustes → Conecta tu agente de IA. Cada agente que permitiste está ahí, y puedes desconectarlo. Un agente desconectado se detiene en su próxima llamada.

¿No tienes navegador? Usa un token.

Para CI, una máquina remota o un agente sin iniciar sesión. Crea uno en la misma página de configuración, en ¿No tienes navegador? Usa un token. Tu agente lo envía como un header:

Authorization: Bearer duct_mcp_…

En Claude Code:

claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

Solución de problemas

¿Atascado? Empieza aquí.

Mi navegador nunca se abrió

Inicia sesión tú mismo: ejecuta /mcp en Claude Code, codex mcp login duct en Codex, o opencode mcp auth duct en OpenCode.

Dice que no pudo registrarse, o “no es compatible con el registro dinámico de clientes”

Actualiza tu agente a su última versión y vuelve a intentarlo. Si sigue fallando, conéctate con un token en su lugar.

Funcionó, y ahora obtiene un 401

Lo desconectaste en Duct, o su sesión caducó después de 90 días sin uso. Inicia sesión de nuevo desde tu agente.

Le pedí que configurara el proyecto y nada cambió

Un borrador nunca sobrescribe lo que escribiste en Duct. Solo rellena campos vacíos o reemplaza un borrador anterior. Consulta la página del proyecto en Duct.

Alojo Duct yo mismo

Usa tu propia dirección de API seguida de /mcp, en lugar de https://api.getduct.ai/mcp.
