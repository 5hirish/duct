Configuración por agente

Ocho agentes. Una dirección.

Cada agente se conecta a la misma dirección. Elige el tuyo.

Claude Code

  1. En tu terminal, ejecuta: 
    claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp
  2. En Claude Code, ejecuta /mcp, selecciona duct y elige Autenticar.
  3. En tu navegador, elige qué puede hacer y luego haz clic en Permitir.
  4. Ejecuta /mcp__duct__insights_brief para ver la guía del informe de Duct, o simplemente pregunta.

Codex

  1. En tu terminal, ejecuta: 
    codex mcp add duct --url https://mcp.getduct.ai/mcp
  2. Luego inicia sesión: 
    codex mcp login duct
  3. En tu navegador, elige qué puede hacer y luego haz clic en Permitir.

Cursor

  1. Añade Duct a ~/.cursor/mcp.json: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. En la configuración de MCP de Cursor, pulsa Iniciar sesión en duct.
  3. En tu navegador, elige qué puede hacer y luego haz clic en Permitir.

Gemini CLI

  1. Añade Duct a ~/.gemini/settings.json: 
    {
  "mcpServers": {
    "duct": {
      "httpUrl": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Inicia Gemini CLI e inicia sesión: 
    /mcp auth duct
  3. En tu navegador, elige qué puede hacer y luego haz clic en Permitir.
  4. Ejecuta /insights_brief para ver la guía del informe de Duct, o simplemente pregunta.

VS Code

  1. Abre la paleta de comandos y ejecuta MCP: Add Server.
  2. Elige HTTP, pega la dirección y nómbralo duct: 
    https://mcp.getduct.ai/mcp
  3. VS Code te pide iniciar sesión la primera vez. En tu navegador, elige qué puede hacer y luego haz clic en Permitir.

OpenCode

  1. Añade Duct a opencode.json: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "duct": {
      "type": "remote",
      "url": "https://mcp.getduct.ai/mcp"
    }
  }
}
  2. Luego inicia sesión: 
    opencode mcp auth duct
  3. En tu navegador, elige qué puede hacer y luego haz clic en Permitir.

Claude, en claude.ai o Claude Desktop

  1. Abre Configuración → Conectores y elige Añadir conector personalizado.
  2. Nómbralo Duct y pega la dirección: 
    https://mcp.getduct.ai/mcp
  3. Pulsa Conectar. En tu navegador, elige qué puede hacer y luego haz clic en Permitir.

ChatGPT

  1. En la configuración de ChatGPT, activa el modo de desarrollador.
  2. Añade un conector con esta dirección e inicio de sesión con OAuth: 
    https://mcp.getduct.ai/mcp
  3. En tu navegador, elige qué puede hacer y luego haz clic en Permitir.

¿Otro agente? Dale la misma dirección o usa un token si no puede iniciar sesión.

¿No tienes navegador? Usa un token.

Para CI o una máquina remota. Crea uno en Configuración → Conecta tu agente de IA, con las mismas opciones. Esa página también enumera cada agente que permitiste y desconecta cualquiera de ellos. Envíalo como un encabezado:

Authorization: Bearer duct_mcp_…

En Claude Code:

claude mcp add --transport http --scope user duct https://mcp.getduct.ai/mcp --header "Authorization: Bearer YOUR_TOKEN"

Preguntas

Las que pregunta la gente. Luego las soluciones.

Antes de conectar

¿Necesito una clave API?

No. Funciona con el plan que ya pagas. La clave guardada es solo para imágenes e informes programados.

¿Cuáles de mis herramientas puede leer?

Stripe, Meta Ads, Mixpanel, GitHub, RevenueCat y el resto los conectas en Duct. Google Analytics, Search Console, Ads y Tag Manager permanecen con el agente propio de Duct por ahora, mientras se confirma la política de Google para asistentes externos.

¿Puede cambiar mi cuenta de anuncios?

Solo como propuesta, si activas esa opción. Espera en Duct hasta que lo apruebes. Ningún agente puede aplicar un cambio.

¿Duct ve mi conversación?

No. Duct solo ve las llamadas que tu agente le hace, nunca el resto de tu chat.

¿Se ejecutará un informe mientras mi portátil esté cerrado?

No desde tu agente. Los informes programados se ejecutan en Duct con una clave guardada, porque el agente de nadie se ejecuta a las 3 a. m.

Si algo sale mal

Mi navegador nunca se abrió

Inícialo tú mismo: /mcp en Claude Code, codex mcp login duct, /mcp auth duct en Gemini CLI o opencode mcp auth duct.

Dice que no pudo registrarse, o “no es compatible con el registro dinámico de clientes”

Actualiza tu agente y vuelve a intentarlo. Si sigue fallando, usa un token.

Funcionó, y ahora obtiene un 401

Se desconectó o no se usó durante 90 días. Vuelve a iniciar sesión desde tu agente.

Una herramienta que esperaba no está allí

Solo ve lo que permitiste. Desconéctalo en Duct, vuelve a conectarlo y elige Trabajar a mi lado.
