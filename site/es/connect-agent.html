Usa Duct desde tu agente. Sin token que copiar.

Pega una dirección en tu agente, haz clic en Permitir una vez y podrá leer y crear borradores de tus proyectos de Duct.

Elige tu agente. Pega una línea.

Claude Code

  1. Ejecuta esto en tu terminal: 
    claude mcp add --transport http --scope user duct https://api.getduct.ai/mcp
  2. En Claude Code, ejecuta /mcp, elige duct, selecciona Authenticate y haz clic en Permitir.

Codex

  1. Ejecuta estos comandos en tu terminal: 
    codex mcp add duct --url https://api.getduct.ai/mcp
    codex mcp login duct
  2. Tu navegador se abre en Duct. Haz clic en Permitir.

Cursor

  1. Añade esto a ~/.cursor/mcp.json: 
    {
  "mcpServers": {
    "duct": {
      "url": "https://api.getduct.ai/mcp"
    }
  }
}
  2. En la configuración de MCP de Cursor, inicia sesión en duct y haz clic en Permitir.

VS Code

  1. Desde la paleta de comandos, ejecuta MCP: Add Server, elige HTTP y pega: 
    https://api.getduct.ai/mcp
  2. Nómbralo duct. La primera vez que use Duct, haz clic en Permitir en tu navegador.

OpenCode

  1. Ejecuta estos comandos en tu terminal: 
    opencode mcp add duct --global --url https://api.getduct.ai/mcp
    opencode mcp auth duct
  2. Tu navegador se abre en Duct. Haz clic en Permitir.

Claude, en claude.ai o Claude Desktop

  1. En Configuración → Conectores, elige Añadir conector personalizado, nómbralo Duct y pega: 
    https://api.getduct.ai/mcp
  2. Pulsa Conectar y luego haz clic en Permitir.

ChatGPT

  1. En la configuración de ChatGPT, activa el modo de desarrollador.
  2. Añade un conector con OAuth y esta dirección: 
    https://api.getduct.ai/mcp
  3. Tu navegador se abre en Duct. Haz clic en Permitir.

¿Te has atascado? Empieza aquí.

Mi navegador nunca se abrió

Inicia sesión tú mismo: ejecuta /mcp en Claude Code, codex mcp login duct en Codex, o opencode mcp auth duct en OpenCode.

Dice que no pudo registrarse, o “no es compatible con el registro dinámico de clientes”

Actualiza tu agente a su última versión y vuelve a intentarlo. Si sigue fallando, conéctate con un token en su lugar.

Funcionó, y ahora obtiene un 401

Lo desconectaste en Duct, o su sesión caducó después de 90 días sin uso. Inicia sesión de nuevo desde tu agente.

Le pedí que configurara el proyecto y nada cambió

Un borrador nunca sobrescribe lo que escribiste en Duct. Solo rellena campos en blanco o reemplaza un borrador anterior. Para cambiar un campo que fijaste, solicita esa edición por su nombre.
