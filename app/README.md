# Duct App

Minimal Next.js app shell for rendering backend-generated reports.

## Current scope (no auth)

- app layout shell
- report list page (`/reports`)
- report detail viewer (`/reports/[slug]`)
- file-based artifact loading from `../backend/reports`

## Local run

```bash
cd app
npm install
npm run dev
```

Open: `http://localhost:3000/reports`

## Data source

The app reads report artifacts generated by backend scripts:

- `backend/reports/*.html`
- `backend/reports/*.json`

Generate example report:

```bash
python backend/scripts/google_ads_brief.py --demo \
  --theme paid_ads \
  --output-json backend/reports/google-ads-report.json
```

## Boundary

- Do not move Python synthesis/render logic into this app.
- Keep report generation in `backend/`.
- Use this app as a viewing layer while MVP remains report-first.
